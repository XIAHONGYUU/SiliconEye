1. 冻结任务ID、照片窗口、输入哈希、模型/提示版本及允许使用的上下文。
2. 输出先保存后评分，人工修订形成新文件；对H01–H06按rubric分别记录各考点，不能强行合成准确率。
3. H07/H08报告已知断言正确/错误/漏答、明确保留未知/无依据确定；参考外断言另查，不自动算对错。全答未知也不能通过。
4. 人工另记介入次数/耗时、纠正类型；未记录就是null。H06的1次纠正不代表整项目人审成本。
5. 历史任务只用于回归。未来选择尚未用于提示优化的区域或新芯片，冻结后才作为留出；当前留出任务数0、新模型运行数0，泛化与速度改善未测。

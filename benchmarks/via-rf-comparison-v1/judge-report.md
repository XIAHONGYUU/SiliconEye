# 冻结孔检测比较：独立裁判报告

2026-11-08；只评价冻结测试目标，不改变正式孔身份、几何、物理孔数或连接。

视觉基线与实际 ilastik 随机森林均命中 4/4 个已确认真目标。3 个已确认非孔目标中，视觉为 0 误报、1 unknown、2 无目标候选；RF 为 1 误报、0 仅 unknown、2 无目标候选。RF 在 Q03 把已确认非孔位置报为 via，视觉在同处保留 unknown。本次小样本支持视觉分支更克制，不能外推整体检测性能；也不能把视觉的 unknown 或两路无候选计为确认“非孔”。

## 冻结范围与复核

- 同一 M1 原图；训练 4 裁片（2 真、2 假），测试 7 裁片（4 真、3 假）；原像素矩形不重叠，来源见 [reference.json](reference.json) 和 [独立来源检查](independent-source-check.json)。
- 评价沿用测试前冻结的 [evaluate.py](evaluate.py)，未修改参考标签、数据或指标。原始照片、参考、评价脚本、自检、视觉预测哈希已复核一致。评价输入及其 SHA256 见 [evaluation.json](evaluation.json)。
- 历史人审只提供命名搜索范围内的身份依据；没有稠密像素真值、准确中心、边界或物理孔数真值。命中规则是合法候选框中心落入该范围，候选宽≤50、高≤80、完全位于裁片内。
- 框中心在命名范围外的候选全部未裁决，不算假孔，也不因视觉上可疑而追加标签。本报告不使用 OOB 作为测试精度。

## 结果

| 固定指标 | 视觉基线 | ilastik RF |
|---|---:|---:|
| 真目标命中 | 4/4 | 4/4 |
| 真目标未命中 | 0/4 | 0/4 |
| 假目标误报 | 0/3 | 1/3 |
| 假目标仅 unknown、无 via | 1/3 | 0/3 |
| 假目标无 via 且无 unknown | 2/3 | 2/3 |
| 存在目标内 unknown 的裁片数（可与 via 重叠） | 1 | 2 |
| 非法候选 | 0 | 0 |
| 框外未裁决候选 | 0 | 12 |
| 总候选数（含 unknown） | 5 | 23 |

RF 的 12 个框外候选中，5 个 via、7 个 unknown。RF 目标内共有 8 个 via 候选覆盖 4 个真目标，另 1 个 via 落入假目标；多候选不能解释为多个真实孔。目标级正报中，视觉 4/4、RF 4/5 对应已确认真目标（分别 100%、80%）；这不是全裁片候选 precision，更不是像素或全芯片精度。样本很少、同源且选取了已审目标，不报告总体 accuracy 或方法优越性结论。

| 测试 ID / 参考身份 | 视觉目标内 | RF 目标内 | RF 框外未裁决 |
|---|---|---|---|
| Q01 / 非孔 | 无候选 | 无候选 | 2 via + 6 unknown |
| Q02 / 孔 | 1 via | 2 via | 1 unknown |
| Q03 / 非孔 | 1 unknown | 1 via + 2 unknown | 1 via |
| Q04 / 孔 | 1 via | 2 via | 2 via |
| Q05 / 非孔 | 无候选 | 无候选 | 无 |
| Q06 / 孔 | 1 via | 1 via + 1 unknown | 无 |
| Q07 / 孔 | 1 via | 2 via | 无 |

Q03 的 RF 假阳性框为 `[54,47,60,51]`，中心 `[57,49]`，落入冻结非孔范围 `[15,32,65,97]`；分数 0.786875，高于预设 0.75 via 阈值。这是候选连通分量的外观平均概率，不是经校准的物理孔置信度。Q03 同时的两个 unknown 不能抵消该误报。Q01 在目标内无候选，但裁片边缘有 8 个候选，不能表述为“Q01 整张无孔”。Q06 的 unknown 与真目标命中并存，不按整张拒答计算。

Q04 的 RF 结果沿竖向亮结构分成多个框，Q01 边缘出现密集候选；这是候选形态观察，不据此新增误报标签。评价只保证粗定位命中，不能说明 RF 的框更准确或能分出真实孔数。无候选不等于确认无孔；本轮结果不自动写入生产或升级网络。

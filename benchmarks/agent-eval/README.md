# 历史开发/复核种子集

- v3-seed-v1：V3局部器件/关系复核，10条部分参考。
- roi2-seed-v1：ROI2局部器件/连接及AA/poly身份，10条部分参考。

两批均参与过开发与人工修正，不能作为两个独立盲测数据集。每批一个“多层照片局部任务”，不是把多张照片算成多个独立样本。当前没有Agent预测结果或准确率。

input.json可给Agent；reference.json、人审记录和历史聊天答案不能作为待测Agent输入。建议新会话/隔离上下文运行。现有对象槽位是复核任务，不测发现未知器件的能力。

observations-template.json为格式模板：run_id需替换，模型/提示版本如实记录，空observations不是已经执行的结果。run-log-template.csv只提供人工登记表头；没有数据行，不表示零次介入。

每轮冻结输入→保存未经人工修正的输出→比较部分参考→追加人工纠正与新的参考版本。材料/配准/电气/像素几何参考分开，不因一次身份批准推导完整真值；未来形成更完整、多区域、多批次的数据集，保留开发/回归与留出验证的区分。

详见[格式与运行说明](../../docs/agent-observations-v1.md)。

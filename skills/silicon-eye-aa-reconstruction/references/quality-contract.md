# 接续、质量门与前后比较

修改候选或选择算法实验前读取。这里定义Agent必须执行的交付检查；现有脚本没有自动实现全部材料/语义门，不能把文件存在或软件PASS代替以下判断。未完成必要检查记NOT_CHECKED，不默认PASS。

## 质量提升比较：A / B0 / B1

A是既有AI直接提取/重建成果，B0是算法原始候选，B1是AI指挥算法并复核修订后的同规格成果。先判断目标细节是否改善，再检查整体质量不退化；时间和返工量只作次要指标。只做到不退化不能宣称质量提升。

复用A及已审范围，无需为比较重新直接提取一遍。对选定的真实问题保留三者同坐标对照，主比较A与B1；比较B0与B1解释AI修订作用。材料/结构可以用显式对象与几何表达，不强迫直接路径先转成稠密mask。若不能同规格/同证据比较，记录限制，不将原始mask和规则几何当同类成品。

## 接续与重算

1. 锁定源图哈希、坐标/变换、旧输出版本与处理域，逐项引用人审记录及批准范围；旧候选不是稠密真值。
2. 选择本次模式：复用/展示、局部修订、隔离算法比较。复用/展示不得训练或改材料。算法实验结果不得直接替换主线成果。
3. 列出拟变更区域、原因和影响依赖。源图或变换变化只使相应依赖待核；文档更新不触发全图重算。缺失旧文件先恢复归档，不先重跑。旧证据互相矛盾则局部记录冲突，不能自行扩大全部批准范围。
4. 无明确失败或变更需求的范围直接保留。已有人工身份/隔离/连续性裁决沿用；仅在新证据实质冲突时提交原裁决与新证据供裁决。

## 质量门与阻断行为

| 门 | 核查内容 | 未通过时 |
| --- | --- | --- |
| 来源与可比性 | 同一源图、坐标、有效范围；差异来源/变换有明确映射 | FAIL：不作直接像素比较或替换 |
| 变更范围 | 变更不得超出声明修订域；汇总模式材料逐像素保持 | FAIL：撤回变更，查越界来源 |
| 已审关系不退化 | 相邻AA/双环间隙、条数、连续性、已审凹角/开口；暗纹不挖空，电阻内部与外围环分开 | 明确违背则FAIL；定位不清记NEEDS_REVIEW，不能用矩形清除或猜补 |
| 材料效果 | 对照原图、旧结果检查漏AA/漏环、背景误涂、错连；AI解释所有相关变化，记录证据与未知 | 已知误报未解决则FAIL，保留实验，不交人重复确认 |
| 规则几何（仅重建阶段） | 水平/竖直、有效多边形、阵列尺寸/间距、环与间隙；前后组件/孔/开口和来源对应 | FAIL退回对应范围；源照片倾斜不是此门失败，未知工艺不套数值DRC |
| 替换与晋级 | 上述适用门完成；目标细节改善有证据，整体质量未退化；必要的新语义已裁决 | FAIL/NOT_CHECKED不替换；待审范围不阻塞无关已通过范围 |

PASS仅表示指定版本、范围和检查项通过，不升级精确边界或全幅状态。未知保留真实不确定性，不能把原先正确的区域改成unknown来规避错误；known→unknown必须单列原因。PDK规律用于检查和AI解释，不能凭规律创造无照片证据的结构。

## 比较必须交付什么

优先使用现有报告/数组/映射；没有必要不新增平台或全图计算。比较记录至少包括：

- before/after文件与哈希、源图/坐标、共同有效域、允许变更域、人审记录及各自范围。
- 有同域三态数组时记录变化：0→1、1→0、0/1→unknown、unknown→0/1，域外变化；未知与未处理范围分别列出。计数是变化量，不是识别准确率。直接路径只有对象/几何时，先比较对象、拓扑、边界和来源；必要时同坐标栅格化作辅助，不倒退重做材料识别。
- 受影响对象的分离/合并、连续性、环、孔、凹角/开口变化；未知边缘和裁剪延续单列。逐项引用旧裁决，由AI结合原图解释，不靠算法投票。
- 可复核的原图/前后/变化区同坐标视图；只核查变化及其上下文，无变化范围复用旧验收。涉及人工的新问题附稳定ID、证据、替代解释；按对象跨块汇总，不按N块重复提问。
- 同输入、范围、信息预算和环境下的耗时/资源、人工纠正次数或复核量。未测写未测；局部结果不能推全图性能。首先证明提取质量改善；质量不退化是前提，耗时收益不抵消已审关系退化。
- 最终结论为保留旧版、采用指定范围、需局部修订或证据不足；说明具体重算依赖。禁止以文件数、测试数或unknown增多认定改进。

## 当前案例的接续边界

五例基准见项目benchmarks/aa-skill-baseline-v2.json；仅各自已记的人审范围，不是全幅金标准。既有全幅结果和F01–F12问题继续作为候选/缺陷清单，不能全部提升为已审真值。

aa-native-canvas-v1a保留为失败的全幅外推实验记录，不作为新的默认基线；不要求N01–N12从头验收。先检查五例是否原样回填、对照已有全幅与问题清单，再选择最小修订范围。电阻内部误报是已有结论，不是新的人审问题。仅有语义没有边界时先回查照片，不能将整个电阻框当非AA标签。

全幅R1/R2局部已由用户确认：间隔为非AA，横向基本正常，左右竖向环间隙虽紧但不接触。验收记录在项目benchmarks/aa-full-frame-workflow-v1/human-review-v1.json；相应非AA间隙作为后续局部不退化关系，不重复询问或因间隙窄而并环。该记录不批准框外的整个父对象或全幅稠密像素。

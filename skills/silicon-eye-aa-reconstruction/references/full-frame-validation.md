# 全幅接续验证与封装条件

用于将局部AA方法推进到全幅。不是重新训练全图模型，也不要求用户从头复核全部网格。正式运行从当前全幅矢量层接续，已有裁决与未解问题一起输入；没有全幅成果的新图需先由AI建立整体材料/结构候选，不能把本芯片参数当默认值。

## 执行路径

1. 锁定全幅模型、照片、逐对象来源、保留对象及裁决。当前已有全幅基线保留，不用局部窗口拼出新的孤立坐标系。
2. AI对照原图与旧问题定位具体对象，明确待修订结构和变化域。只修改有依据的对象，样本/中心身份不重复问；无法准确定位旧反馈时给出有编号的宽上下文，而不是猜着修。
3. 使用`silicon_eye.aa_layer_revision`执行锁定修订数据：去除明确误补横环、按已审条数修订结构、纳入人工批准的局部轮廓，或恢复原有源角点对应。局部边缘定位只帮助解释照片畸变，不改变正交成图要求。
4. 固定层的全幅重建坐标与逐对象原生对应分别保存。环/条纹/光照可以让照片边界弯曲；最终几何必须HV。原图叠加不得使用盲目的全局变换，规则版图不直接当照片坐标。
5. 检查变化域、未改对象及保留AA、跨对象间隙、几何有效性/面积交叠；回归已有人工中心和结构，AI自行巡检全幅。中心正确只是稀疏证据，不能推出全幅准确率。
6. 生成一个页面切换原图、旧轮廓、新轮廓和规则AA版图；网格只供AI宏观巡检与查看，不自动新发起一轮人工全图标注。向人只提交尚无裁决的具体问题。

命令形态：

```bash
.venv/bin/python -m silicon_eye.aa_layer_revision --root . --spec SPEC --output NEW_DIR
```

真实锁定例子为项目`benchmarks/aa-full-frame-workflow-v1/spec-v3.json`；其中坐标、搜索范围和原图适用于当前芯片，不能直接移到新照片。默认新目录；未通过不自动更新父模型或CT。spec-v3回放的是当时人审前输出；当前R1/R2裁决查acceptance-v1.json，回放不得把历史remaining_decisions重新当成人工待办。后续新任务先读CURRENT_TASK，再生成本次变化域和裁决依赖。

## 何时可以封装为有明确能力范围的skill版本

| 条件 | 需要的证据 |
| --- | --- |
| 接续有效 | 已审局部/保留对象不回退，源图与旧记录不改；无必要不重训、不重问 |
| 改善有效 | 相同规格A/B0/B1案例及相应人工/原图证据，改善局部而不降低整体要求 |
| 退化被阻止 | 已知失败/越界修改/误连不能冒充通过或替换主线 |
| 全幅流程跑通 | 同一个全幅层、稳定ID、规则几何、逐对象来源、变更记录和可打开的完整复核包 |
| 关键材料问题得到处理 | 不能保留已知误连/漏环仍宣称全幅通过；无法判断的关键结构由人裁决；非关键精细边界可保留有范围的未知 |
| 软件与重放有效 | 相应测试、负例、输入/代码/参数哈希、输出资源/恢复检查；不将这些当材料真值 |
| 能力声明真实 | 标明已见芯片/已审范围、依赖AI和人工的部分、未测的效率/泛化；封装不等于全自动或任意工艺泛化 |

局部环/阵列规律、正交结构、真实隔离/连续性仍是质量要求；不以未知工艺数值DRC作伪精确判定。二值AA-layout.png仅渲染候选几何，未着色不能视为已确认非AA；100条历史算法疑点也不是100个真实漏AA，不能只用覆盖比例自动关闭。

v1仓库封装已具备本芯片人机协作执行证据；封装状态和全幅材料真值批准分开，不能因文件输出或局部裁决就宣称全部像素正确。实际未解决问题与采用版本只查CURRENT_TASK，历史执行记录见项目docs/checkpoints/2026-10-19-aa-full-frame-workflow.md。

# AA 分割与规则重建合同 v7

2026-10-18，用户批准先验照片分割、再验规则几何的顺序，接续[AA优先 v6](aa-first-reconstruction-v6.md)。本合同固定阶段边界；不表示各项质量门已全部实现。

1. 原照片及有效可见区：保留原始字节、native坐标、层名、遮挡及来源，不用重建图替代材料证据。
2. 前景/背景与未知：AI理解材料、提出少量正负样本；人裁决材料身份与关键间隙。未涂色不是负例。训练/调参/检查用途先冻结。
3. 照片分割：脚本计算颜色、局部亮度、边缘与纹理，输出带来源/参数的候选mask。此阶段不补规则环、不填包围矩形、不凭器件先验并岛。
4. 原生材料验收：独立检查AA内部漏检、背景误检、窄间隙、真实凹角和材料连续性。没有人工稠密标签时不伪造IoU或整图召回率；稀疏样本不代替整个边界验收。
5. 正交几何重建：对通过范围进行结构拟合和畸变建模。保持已审组件、内孔、开口和隔离关系；需要改变这些关系时退回原图阶段，不在几何阶段静默“修好”。
6. 前后对照质量门：对同一材料区域比较重建前后的拆分、合并、孔洞、缺口、连续性和来源吻合。有效多边形/HV边/无面积交叠只是一部分技术检查。
7. 输出：共同全幅坐标、稳定对象ID、原生对应、状态和版本化矢量；像素图由规则几何渲染。CT归属必须依赖明确AA版本，AA修订后按依赖重算。

AI负责材料判断、候选样本、异常解释及例外，脚本负责固定分割/拟合/检查/渲染，人裁决关键身份和拓扑。PDK提供合法性检查条件，不替代照片证据，不为“版图通常如此”补出不存在的AA。

当前[算法对照 v1](../aa-segmentation-comparison-v1.md)仅完成第三阶段的探索性比较；其中S03/S05的18个中心已获人工确认，取样邻域仍非真值。后续少量提示RF在12个非训练中心上通过，但随后U已确认为电阻内部非AA；新增U训练提示后出现已审AA点漏检与残余条纹误报，整块mask仍未通过，无方法获全幅生产批准；当前下一步以CURRENT_TASK为准，不能在已看过的窗口调参后宣称盲测提升。

2026-10-18阶段总结：执行方法进一步固化为[AA工作流v8](aa-extraction-workflow-v8.md)，本文的材料先于正交重建、证据与质量门边界继续有效。

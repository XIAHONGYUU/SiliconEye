# 顶层方向 v5：按设计约束重建结构组，再回投照片验证

2026-10-18，接续用户对全幅 AA＋CT v1h 的五点纠偏。本稿接续 v4，收紧主数据、重建顺序及质量门。当前只完成设计纠偏，未实现下列新约束求解或质量门；不修改原始照片、冻结模型和既有人审记录。

## 核心变化与当前实现差距

目标是恢复能够解释照片的规则设计结构。照片提供观测；对象、结构组及规则共同决定候选版图；像素图由候选版图渲染。将独立照片轮廓分别正交化，仍不足以完成重建。

本次核查 `benchmarks/full-scene-aa-ct-v1/model-v1.json`：304 个 AA 几何的所有边均水平/竖直，但新增对象没有结构组模板引用。`scene_geometry.py` 的 `aa_proposals` 逐轮廓拟合，`regularize_axis` 仅有限移动已观察亮点，`ct_proposals` 的正几何判据主要是方孔落在当前 AA 内部；没有构建整组 AA 阵列约束、MOS 接触禁区或完整上下层包围检查。181 个 CT 分组是按 AA 对象分组，不等于设计模板。既有 287 项软件测试不包含这些新设计质量门。

因此 v1h 保留为观察候选及反例来源，暂停要求用户逐 F01–F12 验收，不将该版当成可进入追线的生产材料层。新方案先修正机器能够发现的结构问题，再交付少量宏观歧义。

## 统一工作流

原始多层照片与来源/有效区 → AI 结构观察和分组假设 → 参数化几何与约束图 → 联合拟合版图和各照片成像变换 → 设计规则检查＋独立照片回投检查 → 有范围人工裁决 → 已审分层版图 → 器件/端口/网络分析与输出。

仍使用全幅统一坐标和唯一对象 ID。结构组只是共享参数与关系，不是裁切边界；跨组导体仍可连续。器件粗分类只用于理解/评估，不作为材料抽取分区。几何/材料身份、器件端口和电气连接分别验收。

## 五项纠偏落点

| 用户要求 | 重建策略 | 交付前检查 |
| --- | --- | --- |
| 横平竖直、直角边界 | 当前 AA/CT 样本采用严格 H/V 参数化几何，正交折线保留真实凹角 | 检查所有边、角、网格及多边形有效性；不是仅检查外包框 |
| 底部阵列整齐 | 先识别重复族，估计一个原型和行列间距，再生成实例 | 同族宽高、行基线、列位置、间距、实例数和边界位置一致 |
| CT 合法且重复 | 先确定接触类型/合法区，再用同族模板和观测拟合孔阵列 | 方孔尺寸、行列节距、端部留边、重复单元差异、禁区及上下层包围 |
| 连续结构不残缺 | 已识别连续条/环用中心线、宽度、转角及开闭语义表达 | 检查断缝、颈缩、碎片、环宽和内孔；不得自动封住真实缺口 |
| 正向设计质量门 | 几何、组规律、层间关系和证据回投同时检查 | 每条规则输出通过/失败/待定及依赖；缺层或缺标定不能算通过 |

本次 AA/CT 样本的默认 H/V 是项目重建规则，不声称 GDS 格式或所有工艺只能 90°。GF180 允许 poly/metal 的 45°和 90°转折；若未来有明确特殊结构证据，须显式声明例外，不能把成像倾斜直接保留为设计斜边。[GF180 Layout Information](https://gf180mcu-pdk.readthedocs.io/en/latest/physical_verification/design_manual/drm_03.html)

## 主数据需要补什么

复用现有对象编号、来源记录和人工裁决体系；最小增加结构组及约束，不另起完整数据库或通用调度平台。

- `observation`：源照片 ID、原生位置、亮点/边缘/遮挡、来源证据。观测可碎片化，不强迫原始证据连续。
- `structure_group`：原型类型（矩形阵列、条、闭环、折线、重复 MOS 接触模式）、成员对象 ID、原点、共享宽高、行列数、节距、镜像与例外、分组来源与状态。
- `constraint`：规则 ID、作用范围、参数、来源（用户/观察/PDK 类比）、生效条件和所需材料层；区分硬结构约束、待验证假设及标定后才能检查的数值规则。
- `reconstructed_geometry`：从组参数生成对象几何，引用组/原型与来源；保留每个实例自己的 ID。`observed_supported` 与 `inferred_candidate` 分开，不能把补全几何写成已经看到的事实。
- `quality_result`：规则及对象/组 ID、通过/失败/待定、测量或冲突位置、缺失依赖、回投证据。规则通过不改写人工批准。

例如底部 dummy 应由“原型宽高＋行列原点/节距＋实例索引”生成，而不是一排各自独立、略有不同的矩形。结构族内部硬约束成立后，单个像素峰偏移不能导致该实例单独歪斜；应回查观测、分组或照片变换。

## 孔：先有允许接触的位置，再解释亮点

当前只重建 AA 与 AA 上 CT，不完整恢复 poly/M1，但可以按需建立带来源的局部沟道禁区、上覆材料支持/未知观察，不把这类辅助约束算成完整新层已恢复。

1. 区分 AA 接触、poly 接触与其他未知亮点。AA 上有亮点只是必要观测，不是完整合法性证明。
2. 为每个结构组建立合法/禁止/未知三态接触区。AA 接触需有正确扩散落点与包围，避开已知沟道/禁区；还需上覆导体支持。poly 或 M1 证据缺失时，相应规则待定，不能靠 AA 包含关系宣布全部合法。
3. 同组孔尺寸、行列节距、相位及端部留边由共享参数控制。同构 MOS 重复单元的 CT 模式不一致必须报异常，重新判断漏检、误检、变换误差或真实例外，不直接放行。
4. 允许由充分重复证据产生“模板推断的缺孔候选”。显示与统计须区分已观察孔、推断孔、遮挡/未知和冲突。未经裁决的推断孔不能自动建立确定电气连接。
5. 同组相同模式是设计先验；不同尺寸、边缘单元、不同端子/电流需求或特殊结构可以不同。不按全芯片统一孔数/节距硬套，也不因某个单元少检一孔就自动改成设计缺孔。

GF180 官方 Contact DRC 检查尺寸、孔距、COMP/Poly2/Metal1 包围，并显式禁止栅沟道与场氧上的 Contact；证明“位于 AA 内”不足以判断合法。[GF180 Contact deck](https://foss-eda-tools.googlesource.com/globalfoundries-pdk/libs/gf180mcu_fd_pr/+/refs/heads/main/rules/klayout/drc/rule_decks/contact.drc)

SKY130 的 licon 与本项目 CT 不能直接等同；其规则同样区分接触材料、包围和与栅的关系，且存在特殊接触形状/规则例外。借鉴关系检查，不移植层号、路径或尺寸。[SKY130 licon rules](https://skywater-pdk.readthedocs.io/en/main/rules/periphery.html#licon)

## 连续材料与残余证据必须分开

“残余证据提示”是照片观察支持与当前模型之间的差异，本身可能断续。它不是残余器件、可加工版图或下一步生产材料层，不应作为材料结果混合展示。

生产候选中的已识别完整条/闭环应连续、边宽规则，不能保留噪声锯齿、偶发孔洞或半圈碎片。照片遮挡或低对比处可由结构约束提出连续候选，但补全部分仍是推断；照片边界、真正开口和不能区分的接续保留明确延续/未知，不默认封环或并岛。合法正交多边形的闭合数学边界，也不等于其物理接续已完整确定。

此前 P05/P06 两个折线片段仍保留原有有范围批准；后续通过新版本表达其完整接续，不能把旧局部片段冒充完整材料。连续性只在同一已识别导体/环内要求，AA 岛之间及独立电极之间的分离仍须保持。

## 两条并行质量门与使用条件

| 检查层 | 具体内容 | 当前用途与限制 |
| --- | --- | --- |
| 结构几何 | H/V 边、直角、有效多边形、网格、无伪碎片、规则宽度 | 可用相对单位确定性检查；折线/凹角按模板保留 |
| 重复组 | 共享尺寸、基线、节距、实例数、CT 模式 | 分组和原型须有来源，例外明确，不要求全芯片同一模式 |
| 材料关系 | 孔的合法区、禁区、包围、非预期短接/断裂、闭环连续性 | 缺失 poly/M1 等依赖时输出待定，不能空输入通过 |
| 证据吻合 | 规则几何回投原图，独立对应点、宽上下文、真缺口与隔离、观测/推断差异 | 不只检验用于拟合的点；不能以任意变形掩盖错误模板 |
| 工艺 DRC | 目标 PDK 对应层、尺寸、空间与例外规则 | 芯片工艺和尺度未定，当前不能宣称正式 DRC；数值项待定 |

设计规则检查与照片证据检查必须同时成立：规则正确的多个版图都可能解释局部照片；DRC 不能单独证明复原正确。照片看着像也不能覆盖组约束失败。现阶段称“重建规则检查”，不称“目标工艺 DRC 已通过”。等工艺、标定、完整相关层和规则 deck 明确后，才增加正式 DRC；同一规则结果仍不等同 LVS 或电气功能确认。

组约束变更若触及旧对象，只在新模型修订，不覆盖冻结版本；继承原身份/结构裁决，不自动继承精确几何批准。新旧 ID 映射及受影响对象/材料关系应可列出，必要时只让用户裁决变化处，不把全体已审对象机械锁死到无法纠正成像误差。

## 分工及最近实施节点

AI 识别结构族、原型、合法接触区与替代解释；脚本拟合共享参数、生成实例、检查约束、渲染与回投；人只裁决结构归属、关键例外和影响连通的歧义。照片亮度阈值继续提供观测，不再主导成品几何。

下一步用同一全幅空间建立三个最小对照：底部 dummy 阵列、一个连续 AA 环、一组重复 MOS 的 AA＋CT 模式。窗口只作验证；不改变全幅生产范围。先形成分组/约束及参数表，再实现最小共享参数拟合和质量检查，复用既有切层页显示规则版图、来源回投与推断状态。对照必须包含歪行/不等尺寸、少孔/多孔/禁区孔、环断裂等反例，证明质量门能拦截；不增加全幅候选数量来代替质量改善。

交付应包含：模型/组参数、约束结果、旧新对照、原图回投、确实需要人工的少量问题。机器规则失败先修；不可判定项列依赖；无本质歧义不交回逐孔复核。完成该节点后再按相同约束扩展全幅，暂不开展其他材料完整重建、网络追踪或 skill 封装。

# 顶层方向 v4：以规则几何版图为工作数据

当前方向由 [v5 结构组与正向规则纠偏](photo-stack-workflow-v5.md)接续；下文保留历史设计。

2026-10-18，接续用户对“照片分割形状不应直接成为后续版图”的纠偏。本稿接续 v3；全幅统一空间、区域观察不裁割材料/网络、原图不可变的约定保留。

## 主干

原始多层照片 → 来源/有效覆盖整理 → 结构观察与约束假设 → 统一版图坐标中的规则矢量几何 → 回投照片及结构质量门 → 器件、端口与连通分析 → 编号、统计、电路图、点亮及其他输出。

主数据采用带编号的矩形、环和正交多边形、阵列及其关系。像素图由版图数据渲染；照片分割结果用于支持观测、发现遗漏与检验候选，不再直接定义生产版图边界。保留将来表达非正交真实结构的能力，不强行美化所有形状。

## 三种空间与证据

1. 源照片原生空间：每帧保持完整尺寸、哈希与原始坐标；遮挡、噪声和物理成像不确定性不消失。
2. 重建版图空间：全幅统一坐标；近似横平竖直、重复间距/尺寸及孔阵列可作为显式待验收约束。尺度未测量前使用相对单位，不能冒充微米或原始 GDS 网格。
3. 回投空间：用可追溯变换将规则几何映回各原图。检查结构解释、间隙、材料归属及偏差；不能用“已经正交”代替配准验收。

全局旋转、透视和局部成像畸变需分别验证。单应矩阵只建模平面透视，不能声称解决任意镜头畸变。允许在有足够对应结构时增加局部模型，须防止折叠、改变拓扑或用任意拉伸消除真实矛盾。

## AI、脚本和人工

- AI：综合照片提出对象身份、几何类型、重复规律、断开关系、约束与替代解释；记录证据和未知。不是把亮像素直接叫作材料真值。
- 脚本：拟合候选变换和几何、正交/阵列约束、来源检查、矢量和像素渲染、回投、碰撞及分离检查。
- 人工：裁决改变几何解释或连接关系的关键歧义；不要求逐孔确认。

暂不封装新的 skill。先通过样稿检验观察格式、约束、回投及质量门是否可用，再决定通用能力边界。

## 本轮最小实施

[AA＋CT 规则几何样稿](../geometry-reconstruction-v1.md)在完整场景中建立少量明确对象，用宽视野窗口检查；这是稀疏方法验证，不是重新按器件区域分割的生产路线。未建模部分是未知，最终材料层和跨区网络仍须覆盖整个可见场景。

首版仅支持矩形、矩形环和两个 CT 阵列。没有恢复任意正交多边形、全幅几何、真实工艺尺寸、GDS 导出或电气连接。质量门先检查：几何规则性、来源/回投、原有分离不被破坏、未知不冒充材料存在，再进入人工材料审查。通过后扩展表达能力和场景覆盖，而非回到掩膜边缘修补。

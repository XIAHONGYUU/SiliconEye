# AA提取工作流 v9：AI主导、算法辅助，以质量提升为目标

2026-10-19。按用户再次纠偏制定。承接[v8](aa-extraction-workflow-v8.md)与[材料/重建合同v7](aa-segmentation-contract-v7.md)，替代当前skill中“先跑算法、再不断补审”的默认路径。本次是流程修订，不是新的提取运行或效果验收。

## 目标与既有质量基线

用户判断：加入算法前的AI提取已基本满足需求；加入算法是为了比较与改善细节，不是降低成图质量、缩减流程或重新开始。既有直接提取成果、人工修订及其批准范围共同构成工作基线；保留仍待解决的缺陷，不将“基本满足需求”扩大成精确像素/全幅正式验收，也不因没有稠密mask真值而否定已完成的结构工作。

优先级：材料身份与覆盖、结构/拓扑正确、规则几何和细节质量；其后才比较效率与人工负担。新算法保留试验价值，但只有目标细节有证据改善、其他适用质量要求未退化时，才能替换对应范围。仅保持不退化或更快，不足以宣称本轮质量提升。

## 主流程

1. **接续已有整体判断与成果**：读源照片、已有AA层、已审结构及问题清单。AI先理解整个视野的MOS、外围环、dummy、电阻内外及邻近关系，形成/更新全幅AA对象判断。区域用于上下文与评测，不切断层或跨区域对象。
2. **AI确定材料与结构**：辨别哪些是AA，条数、分离、连续性、环和缺口是什么；暗纹、CT亮点和上覆金属不直接改变AA。已有结论直接沿用，必要时回查原图或工艺资料。AI根据图像证据作判断，不只是给算法挑参数。
3. **按细节问题选择执行方式**：已有质量足够的范围保留；需要提高边界、暗区覆盖、细环/窄间隙或凹角质量时，选择下述直接路径或算法辅助路径。不是每个区域都重跑两遍，也不强制新增样本/重训。
4. **AI修订并形成同规格成果**：AI对照原图、宽上下文与既有裁决，处理遗漏、误报、误连、内部破碎及算法分歧，定位有证据的材料边界；脚本负责坐标、绘制、拟合和检查。算法一致不代替材料判断。真正不清楚的边界局部保留未知，不能用大片unknown替代本可完成的识别。
5. **规则几何重建与质量检查**：对应范围材料/结构有依据后，恢复水平/竖直的几何、重复阵列与规则边界，保留源图映射和局部不确定性。先验不用于虚构环或连通；不要求整图逐像素人工批准后才允许对已审范围重建。新精确几何仍是候选，不能自动提升批准状态。
6. **前后质量比较和交付**：用同坐标原图与前后成果检查整体和细节；先由AI修复已有错误，再把必要的新歧义交给人。按通过范围接续AA层；CT在明确AA版本后单独推进。

## 两条路径、相同的终点

| 路径 | 处理方法 | 必交结果 |
| --- | --- | --- |
| A：AI直接提取/重建 | AI看照片与上下文确定AA对象/边界和结构，现有脚本将显式判断落成几何/图层 | 有来源的AA层、规则几何、未知与质量检查 |
| B：AI指挥算法并修订 | AI给算法指定任务、范围及必要样本；算法产生边界/纹理候选；AI复核修订，再形成几何/图层 | 与A同规格的最终成果，另保留算法原始候选与AI修订差异 |

“直接”不排除脚本绘图和几何运算；“算法辅助”不把RF/GrabCut输出当成成品。完整稠密分割mask不是A路径的强制前置产物；材料证据、结构判断与来源映射才是必要依据。不得用算法原始mask替换A的规则几何后声称完成升级。

已有可用A成果先复用；B只在确有目标细节时试用。算法的颜色、纹理、结构和边缘各有适用范围，不强制固定算法、不简单并集或投票。若B不如A，保留A并记录算法适用限制，而不是降低标准或让人重验整图。

## 比较什么，如何认定提升

一次针对一个明确缺陷，优先使用已经审过的代表性案例；不重新铺开N01–N12。固定源图、范围、批准记录、上下文与最终输出规格，保留：

- A：既有AI直接提取成果及已知缺陷。
- B0：算法原始候选，仅用于解释算法贡献和失败。
- B1：AI指挥算法、复核修订后的最终成果。

主比较为A与B1，B0与B1揭示AI修订的贡献。三者来源、先验/样本、可见上下文、人工干预和参数需明确记录；不能把B新增的人工答案当算法独立提升。无法同等比较时写明限制，不报伪准确率。

| 维度 | 必查内容 |
| --- | --- |
| 整体覆盖 | MOS AA、外围环、dummy是否遗漏，非AA是否误涂 |
| 结构正确 | 相邻AA/双环分离，环的条数与连续性，凹角/开口，内部暗纹不挖孔 |
| 边界细节 | 窄间隙、折线、薄环、明暗变化下的位置与宽度；尺寸未标定则只用像素/相对关系 |
| 重建质量 | 水平/竖直、有效多边形、重复结构规律，照片畸变与几何重建映射，前后拓扑一致 |
| 不确定性 | 不把未处理算背景、不用unknown隐藏退化，未知要有局部原因和范围 |
| 人工负担/效率 | 新纠正次数、需要复核的范围、运行与修订耗时；仅次要指标 |

目标缺陷确有改善且其他适用项无退化：采用该范围；相当：不宣称提升，默认保留已有成果；变差：拒绝替换并定位原因；证据不够：不宣称提升，只保留可复核候选。无稠密真值时可作有证据的定性比较，不要求为了出分数再全图标注。

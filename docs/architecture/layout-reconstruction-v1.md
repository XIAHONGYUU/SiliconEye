2026-10-19，依据用户最新方向。目标是恢复结构合理、规则且可追溯的多层版图。照片是器件/材料存在与形状的证据，摄影投影不是最终版图坐标的定义。当前没有已确认工艺、物理尺度或完整网表，不能声称真实工艺DRC/LVS通过。

## 分开保存四类信息

| 信息 | 作用 | 变更方式 |
| --- | --- | --- |
| 原始照片、人工标注及裁决 | 底层证据 | 原样保留 |
| 原生来源轮廓与跨层对应 | 说明对象来自哪里、对应哪些特征 | 新版本记录变换、误差与不确定性 |
| 材料、器件、相邻关系假设 | AI结合上下层解释结构 | 保留已审身份/隔离，新增关系待核 |
| 多层规则重建几何 | 后续层恢复、端子与电路的工作输入 | 在证据和结构约束下定向调整AA/POLY等工作几何 |

已审大体范围不等于将摄影坐标永久固定为设计坐标。已审材料身份、分离关系和器件/net编号不能因几何微调被悄悄改变；几何修改另存候选与前后差异。

## 推进顺序

1. 从照片与既有成果确认材料存在、基本形状、重复结构和器件范围，不从规则凭空制造器件。
2. 明确每条栅与哪个器件AA关联，端部是什么类型，是否存在共同列/匹配关系；不把最近的AA自动当作正确AA。
3. 在规则坐标中联合重建。普通MOS优先矩形栅体；端部需要完整长度，不能自动加狗骨头。特殊形状需要单独证据。
4. 用层间关系检查：栅跨越指定器件AA，适当伸出两端，避开无关环AA；匹配排共列，保留适用的尺寸/间距一致性。电阻、场区POLY和已审特殊器件按其类别处理。
5. 照片叠加用于追溯、发现错误解释和检查对应，允许摄影畸变使它不完美重合。照片对应失败时停用误导叠加，已有明确AA关系的设计候选仍可单独生成。
6. 矛盾时回查多层。可微调POLY，也可对AA提出有来源的工作几何修订；不能为了得到PASS而任意挪AA或填补材料。每次保留原版本、理由、拓扑不变项、目标改善与剩余歧义。

## 三类质量门分别报告

- **证据与识别门**：材料是否存在、数量及所属器件有无依据；假设与人工裁决不混淆。
- **通用正向结构门**：矩形/正交、共同列、目标AA交叠、两端伸出、避环、隔离、完整主体/引出。相对像素预算只验证当前几何，不是工艺最小规则。
- **工艺与电气门**：工艺/尺度确定后运行适用PDK DRC；端子/网络证据齐备后检查电路连接。前两类PASS不替代这一步。

“有AA交叠”只是必要条件；把多出来的栅挪进AA不能证明它真实存在。按规则生成的自洽图也不是独立的识别准确率，需要照片证据与人工复核，不能把约束构造成功当作材料真值。

## 局部修改与迭代边界

2026-10-19用户确认下方联合图与F05-GATE展示范围；F01–F04小MOS识别未通过，见[人工裁决](../../benchmarks/poly-full-frame-v3/human-review-v2.json)。不能把整齐的模板展开当成小MOS栅识别通过。

**当前实现**：JSON保存来源轮廓、规则几何与组参数，Python生成SVG和照片叠加副本。下中部联合工作几何另存joint模型，不能将摄影复核atlas误当共同设计坐标。原图不修改。页面可切层/缩放，尚无交互顶点编辑器；生成器已有整组参数、已审对象冻结与跨排对齐，但没有统一的逐对象点/边修订输入。直接改生成结果会被重跑覆盖。

**后续局部修订的要求（接口尚未实现）**：修改记录必须指明版本、层、对象ID、坐标空间、点/边/整对象或组的作用范围、前后值及依据。优先修改持久输入，生成新版本；不以临时改SVG或生成模型代替可复现修订。

- 来源观察点可以单点微调，保留其对应与不确定性。
- 规则矩形通常微调一条边（联动两个顶点）或宽/长/位置；独移一角会产生斜边，不能静默破坏正交。折线多边形同样维护相邻边正交。
- 个别对象的修订不得自动扩散到整组；确需调整共同列、尺寸或间距时显式声明联动对象。规则冲突应报告，不自动改其他层以掩盖问题。
- 仅重新生成受影响视图并检查必要的邻近、层间和共享约束；输出前后差异、受影响对象及未修改对象保持性。已审身份/隔离裁决不因位置修订自动改变。

因此，多层几何持续微调在数据结构上可行，但“无需临时改脚本、逐对象持久修订并自动限定影响范围”的便捷入口仍待补齐，不能称为现成功能。

## 主流程

原始照片与来源 → 代表性材料笔画 → 多算法候选 → 同坐标分歧图 → AI结合上下文复核 → 关键结构人工裁决 → 有证据的局部修订 → 材料质量门 → 正交几何重建。

材料质量门以前不将照片上的亮边直接当成最终GDS边界，不同时推进CT归属。目标仍是全幅共同坐标的AA层，器件观察区和评测窗口不切断后续跨区域层恢复。

## 责任分工

| 执行者 | 固化职责 | 边界 |
| --- | --- | --- |
| 脚本 | 读取锁定照片、栅格化显式笔画、生成特征与算法mask、计算检查分数/分歧、绘图、版本与来源检查 | 不自行认定材料身份，不凭亮度填环或并网 |
| AI | 选取代表性样本，辨认材料与结构，结合宽上下文和已审事实解释冲突，必要时回查PDK | AI判断单独留记录，未知不能以经验补成确定边界；尚无独立运行时视觉模型接口 |
| 人 | 裁决关键身份、隔离、连续性与难辨边界 | 笔画批准不等于全mask批准，结构批准不等于精确尺寸批准 |

AI可以使用正向版图经验：AA环、隔离、内部连续性和重复结构有规律。但这些是解释/检查条件，不能直接套用未知工艺的数值DRC，不能凭一般规律补出本图无证据的结构。

## 样本与算法

- 原始照片不可改；保留原生像素、有效范围、来源哈希、稳定观察ID和裁决版本。物理尺度未知。
- 训练用少量覆盖亮暗纹理的笔画，而非仅用孤立中心。背景样本要覆盖电阻条纹和真实窄间隙；AA样本覆盖暗MOS内部与环横条。未标位置保持未知，不把整个复核框变成稠密标签。
- 已审A01–A05与N01–N04作为局部训练基准。N05未在样稿出现，不补造。原12检查中心及其半径10方形避让区不训练；同窗口上下文仍相关，不称盲测。
- 纹理RF为当前主候选；纹理＋结构RF、GrabCut与简单阈值提供参照。保留全部结果和固定种子，不挑最好种子发布。
- 分歧图用严格一致/冲突类别，不多数投票、不简单并集/交集。相关方法的一致不是独立置信度，算法一致也可能共同出错。

## 质量门与失败回退

1. 来源/软件门：输入、坐标、样本冲突、训练/检查分离、代码依赖、输出可恢复。
2. 材料门：独立检查已审AA漏检、非AA误报、内部覆盖、环保留、真实间隙。中心全对仍需区域复核。
3. AI/人工语义门：身份、隔离、内部连续性与精确边界分开记录；未知边界保留unknown。不得按Q框直接裁切。
4. 重建门：材料通过后才正交化；对照拆分/合并、内孔、开口及来源对应，不能借重建改掉真实拓扑。

失败时回到对应样本、语义或边界证据；保存失败版本，不用膨胀/矩形填充掩盖。照片已有畸变，图上局部倾斜与预期正交设计应通过重建映射处理，不强制源照片笔画横平竖直。

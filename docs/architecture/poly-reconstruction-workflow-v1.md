# POLY工作流 v1：从已审身份到规则几何

POLY接续AA的AI主导方法，算法用于补充边界支持，不替代上下文判断。目标为有原图对应、横平竖直且保持已知分离关系的几何；照片上的倾斜可以保留在来源轮廓中。

## 五步及进入条件

1. 冻结AA模型、批准范围与未知，不因进入POLY重做AA。
2. 复用原蓝色标注、局部修正及ROI2身份。旧正例mask与两种未知同时读取；原0不等于确定非POLY。
3. 比较A直接观察、B0算法支持、B1规则候选。分别验证横向、竖向和遮挡上下文；相同案例不同窗口不能统计为独立样本。
4. 局部方法证明可用后，扩展全幅的主体、端部、连接片及未知覆盖。保留同一原生画布，区域只用于检查；跨层共同布局须有适用配准。局部逐对象矩阵不能冒充全幅配准。
5. 完成全幅接续、不退化和真实问题改进验证后封装POLY skill；能力与未验证范围写入声明，不先建空skill。

## 工具与AI职责

工具按AI指定的主体、搜索范围调用局部GrabCut，排除候选遮挡，在主体切线方向分箱估计法向边界，并限定改变量；AI核查是否仍为同一材料、是否吞并背景或CT、是否保留分离。证据不足则保留A，不将算法输出升级为材料真值。

当前工具只测主体法向边界，不测真实端点，不自动识别完整栅、器件、CT归属或网络。参数为当前像素工作参数，不是工艺规则或概率置信度。正交几何单位是相对布局像素，不是μm。

## 质量门

- 来源门：原图、旧批准/未知、AA版本、参数和代码哈希可核查；原始证据与候选不覆盖。
- 结构门：输出布局边为水平/竖直、对象合法、两栅不误并；正交化有原生对应，不以美观代替材料证据。
- 未知门：遮挡和未处理位置保留-1，不当成非POLY；主体片段封口不当成真实端点。
- 接续门：不改旧材料身份/局部断开，不由远处金属连接反推POLY桥，不用AA限制POLY范围。
- 改善门：同范围比较A/B0/B1，人工/AI结合照片判断新边界是否改善。软件通过和边界移动量均不证明更准确。
- 全幅门：核查覆盖、规则性、隔离、连续结构和对应来源；只提交新增歧义，不要求重新判断全部已审身份。

当前结果、证据与唯一下一步见[CURRENT_TASK](../../CURRENT_TASK.md)。

## 竖向复核纠偏：完整外形先于边缘优化

用户批准P-H01蓝色位置/宽度；P-V01蓝色较黄色贴合，但明显小于实际尺寸，不能作为完整POLY几何采用。旧core只是确定内部支持，既不是完整主体范围，也不是端点。当前工具只调法向且保留切线端点，因此先天不能解决整体尺寸恢复；放大搜索半径不能代替重新识别整个对象。

修订顺序：AI从宽上下文识别完整候选 → 用已审内部core作正例支持 → 分清真实边、接触引出和观察裁切 → 在适用局部对应下参考AA沟道/上下层结构 → 算法辅助边界 → AI修订规则几何。完整候选未形成前不继续全幅复制小core，也不伪造完整栅尺寸。

新增完整范围门：逐对象区分core支持、完整候选外形、真实边界未知、观察裁切；任一方向仍只覆盖内部支持，则标记fragment，阻止其升级为完整layer重建。人审明确偏小时判FAIL，即便相对A更好、正交和不交叠通过，也不能放行完整几何。检查两端越过AA的合理关系，但不强制每个POLY都与AA重叠；电阻体和场区引线也可在AA外。

POLY照片可同时显示AA、栅、CT残留及纹理。AA暗线是用户提供的沟道定位线索，需结合POLY连续形状与重复器件关系核查，不能将任意暗纹自动标作POLY。器件分类帮助查找，不把区域标签直接转为材料mask；本芯片电阻区域需主动检查POLY，通用工艺中电阻还可能由扩散/其他材料形成。

### PDK结构回查（2026-10-19）

- [GF180层关系定义](https://gf180mcu-pdk.readthedocs.io/en/latest/physical_verification/design_manual/drm_07.html)：栅为Poly2与COMP交叠，用于解释关系，不推定本芯片工艺。
- [SKY130层定义](https://skywater-pdk.readthedocs.io/en/main/rules/layers.html)：gate为poly与diff交叠。
- [SKY130 poly规则](https://skywater-pdk.readthedocs.io/en/main/rules/periphery.html)：poly可超出diff形成endcap。只借结构原则，不将其微米数值套到未知工艺照片。
- [SKY130电阻类型](https://github.com/google/skywater-pdk/blob/main/docs/rules/device-details/res_generic/index.rst)：同时存在poly与扩散电阻，不能把“电阻区域”无条件当作poly层真值。

反馈和最新上下文见[修订页](../assets/poly-reconstruction-context-v2/index.html)；原报告不回写批准状态，保持历史。

## 全幅反馈后的必查项

- 已知含POLY的观察框必须继续恢复主体候选；“未知”只保留在尚不明确的边界/引出上，不能长期代替已知材料的处理，也不能将整个框涂为POLY。
- 匹配排共享列位置、间距及适用宽度。照片的偏移只保留在来源几何中；公共规则图必须验证跨排约束，不能只检查每个矩形是否正交。不同类型的器件不强制同尺寸。
- 主体以外的接触端POLY也属于层恢复范围。主体、扩宽/引出、CT归属是不同结论；端部模板必须保留来源与候选状态，不从存在CT直接推导电连接。
- AA/POLY联合验证需要有适用的局部对应，拟合点与检查点分开。局部配准失败禁止渲染误导性叠加。成功工作门只证明选点自洽，人工未审不能自动升级为全幅对应。
- 复用AA的真实记录几何和对应；非矩形结构不能用外接矩形替代。联合视图是派生层，不覆盖原图、已审AA或局部POLY。
- MOS的栅体应和对应AA关系合理，端部可在AA外；电阻POLY也可在AA外，不能要求所有POLY都被AA包含。联合检查发现冲突时保留“坐标/AA/POLY”多种解释，不强行改掉某一层。
- 更改未审阵列数量时保留旧记录并退休旧候选ID，避免用同一ID暗中指向另一位置。既有器件/net编号不随候选重排改变。

本轮[定向修订检查点](../checkpoints/2026-10-19-poly-full-frame-v2.md)记录执行证据；该方法仍待新端部样式和局部配准人审，不把软件通过等同于skill完成。

## 顶层方向修订：结构重建优先于摄影投影

依[联合版图重建架构](layout-reconstruction-v1.md)执行。普通MOS不再自动生成凸形/狗骨头端部，端部长度仍需恢复。指定器件AA、避环、伸出和匹配关系决定设计候选的相对位置，照片投影另作证据追溯；不以像素重合要求覆盖这些结构关系。

AA/POLY工作几何可在上下层证据下联合提出新版本，原图与人工身份/隔离裁决不改。自动结构门只能检查声明约束，不能凭规则制造器件或把错误栅强行塞进AA。未知工艺和尺度下不称作真实PDK DRC通过。

[本轮落实](../checkpoints/2026-10-19-poly-full-frame-v3.md)仅完成下中部设计候选、普通端部策略和F05新范围，仍待真实关系复核，不将其升级为全幅完成或skill封装通过。

## 收口门补充（2026-10-20）

- 通过显式范围替换旧候选，保留退休ID与原记录；新旧不同坐标的几何不能直接拼接。共同工作坐标、来源坐标和旧已审显示范围分别保存。
- 结构组的名称不是对象语义。含GUARD的组可能同时含器件AA、dummy和环，质量门读取显式对象角色。
- 全幅扫描中的数量替代解释不自动成为材料事实，不为通过正向结构门调整数量。未裁决的替代图不写入有效对象，批准范围也不从一个窗口扩散到全图。
- 目标AA交叠/端部满足后仍需查非目标AA；保留真实冲突并阻止定稿，不隐去AA或降低预算。来源轮廓分离也不等于物理必然分离，须回看原照片与人工裁决。

# 分层重建纠偏 v6：先完整 AA，再解释 CT

2026-10-18，接续[设计 v5](photo-stack-workflow-v5.md)与全幅 F01–F12 人工复核。本文调整当前开发顺序；不表示新 AA 已完成重建或新质量门已实现。

## 本轮结论

[原始逐窗裁决](../../benchmarks/full-scene-regular-v1/human-review-v1.json)锁定被审模型、页面和窗口的 SHA-256。十二窗均有修改项；“MOS AA 基本正确”只保留为有例外的局部肯定，不等于 AA 完整性或 CT 归属通过。旧模型与195个保留对象不覆盖，CT 结果冻结作历史候选。

代码核查：`regular_scene.run` 先合并旧 AA、调用 `regularize_aa`，然后才调用 `contact_candidates`。所以没有证据表明 CT 算法直接改坏了 AA；问题是两个任务共用未通过完整性验收的中间结果。`regularize_aa` 只规整已有矩形组、已有带内孔环的壁宽，没有搜索并恢复所有缺失环。活动多边形有效、正交、无交叠检查也不会发现完全没有生成的环、MOS 或 dummy；错误粘连的外包框仍可能通过这些检查。

全幅叠图中可见多个白色外围结构未被青色 AA 覆盖，部分内部已有覆盖。该观察支持系统性覆盖缺口，但不代替每一条边界的材料身份判断。F06 错误补块及 F10 粘连先作为明确修正项；精确对象 ID、分离边界需回到原图定位，不能只凭窗口文字自动删形。

## 新的阶段边界

1. **AA 观察与结构清单**：全幅寻找器件扩散、保护/衬底环、连续条、折线及 dummy。每项有源坐标、候选身份、隔离关系、开闭/延续状态和证据；原有区域框只用于核对，不裁割材料。CT/M1 允许辅助理解，不作为 AA 必须存在或不存在的条件。
2. **AA 规则几何重建**：按矩形、正交多边形、环中心线/内外边界、重复阵列生成共同场景几何。先解释连续材料，再处理遮挡或照片畸变；禁止以一个大矩形填平多个倾斜 MOS 之间的隔离。
3. **AA 独立验收**：通过结构、覆盖、隔离与照片证据四类检查；未知/照片外显式保留。输出可版本化 AA 矢量、渲染掩膜、有效覆盖与未解决项。冻结 AA 修订后才启动本轮 CT 重算。
4. **CT 观察与归属**：所有亮点仍可作为观测保存；区分 AA 接触、poly 接触与未知。结合相应材料、沟道/禁区及上覆支持，建立孔阵列；不能因为未落入当前 AA 就直接判为 poly CT。缺少必要依赖时保持未知。

AA 修订必须列出受影响的 CT/材料关系，后续只重算依赖结果，不继承旧 CT 归属。旧的孔存在性与整体排列裁决保留原范围；新落点不得继承未经核对的归属批准。

## 环的判读规则

AA 环、CT 阵列、M1 是三个独立对象。常见重叠结构可以提供正向设计先验，但 CT 或 M1 为布线留下的断口，不足以证明下面 AA 也断开。环的侧边可能因为对比度、上层遮挡而呈亮点状；应追踪同一 AA 内外边界、转角、条宽与包围关系，不能把亮点直接当成离散 AA 岛。

同样不能把所有框都补成闭环：真实开口、独立扩散岛、照片裁切、界面遮挡和无法区分的接续必须保留。完整闭环候选可用结构约束补充弱证据边，但补充部分必须标记推断；不自动赋予衬底连接或电气连通结论。

## AA 质量门与反例

| 门 | 要检查的事 | 必须拦住的反例 |
| --- | --- | --- |
| 几何 | 所有边正交、多边形有效、规则宽度与节距 | 歪边、破环、dummy 不等尺寸/间距 |
| 覆盖 | 源图结构清单逐项对应已建模/未知/明确排除 | 完全漏环、漏整组 MOS、阵列缺一个实例；不能靠对象数量或已生成对象检查通过 |
| 隔离/连续性 | 器件 AA 与环间隔、环内孔、相邻 MOS 分离和真实连续段 | F06 填中间空隙，F10 管子与环粘连；CT/M1 缺口导致 AA 假断 |
| 证据 | 原尺寸回投、宽上下文及逐对象映射，独立边/转角核对 | 规则几何很漂亮但落错材料；拟合点自证；变形掩盖错误连接 |

覆盖清单由 AI 观察与人工裁决共同建立，不是独立真值。缺失独立观察时该项为待定，不能用现有模型反向生成清单后宣称完整。几何门 PASS 不能抵消覆盖门 FAIL；当前整图 AA 人审完整性为失败，CT 归属质量门暂停。数值工艺 DRC 因工艺与尺度未知保持待定。

质量门实现后需注入：删环、断环、删 dummy、合并器件与环、MOS 间填块，以及仅删除 CT/M1 而保留 AA 的对照。最后一项应保持 AA 连续性，不得误报 AA 缺口。软件故障样本与这颗芯片的人审回归分开，均不称盲测。

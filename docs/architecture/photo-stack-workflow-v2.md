# 从照片到可修订分层版图：顶层设计 v2

> 2026-10-18 后续纠偏：[顶层 v3](photo-stack-workflow-v3.md)明确在完整视野上进行分层抽取，区域观察仅作理解与评测。本文保留历史，原 Q1/Q2 局部分层优先路线已被替代。

2026-10-18，依据用户批准的顶层讨论。本稿取代 v1 的近期实施顺序；v1 中的证据、稳定 ID、原生坐标及已实现接口约束仍保留。本文是已采纳的架构方向，不表示下列 skill、标准照片栈接口或自动提取引擎已实现。

## 主干与工作对象

标准照片栈 → 整体区域规划 → 可修订分层版图 → 器件/端口与网络联合提取 → 多种输出。输入质量门先判断任务可用性；各阶段再检查自身产物，不能用一个 PASS 批准所有用途。

原图不可变，是证据底座。后续正常计算读取重建版图；出现歧义或矛盾时允许回查来源照片，修订局部几何并重算受影响结果。不得断开原图与重建对象的来源关系。

照片帧与语义层分开：一张照片可能支持 poly 与 CT 等多个层；一个语义层也可能需要多张照片。重建层不是简单给照片改名，不宣称复原了原始 GDS 的全部设计意图、隐藏掩膜或实际工艺参数。

## 共同数据约定

1. 照片栈：chip_id、scene_id、frame_id，原图路径/哈希、层名及其依据、拍摄来源、原生坐标、有效范围、遮挡、尺度状态。公共参考坐标及变换另外记录；不把同尺寸当作已对齐。
2. 分层版图：layer_id、栅格掩膜/标签、对象标识和可选轮廓，保留 native→reference 变换版本、来源、修订及适用区域。像素图是几何数据的一种表示，不是唯一事实存储。
3. 像素状态至少区分“材料存在、材料不存在、不可判定”；另存有效覆盖掩膜区分未拍到区域。边界精度、材料身份和连接批准分别记录，不能用二值背景吞掉未知。
4. 对象关系：region、shape/conductor、contact/via、device、terminal、net、group/cell 分别有稳定 ID。沿用 R2_Q1/R2_Q2 等已有身份，不能因重画或遍历顺序重编。合并/拆分保留继承、别名及旧版引用。
5. cell/group 是层次或组合；device 是器件实例；finger 是物理栅指。统计分别列出候选/确认、范围和归并规则，不把指数量等同 MOS 数量。
6. 输出均绑定同一状态修订：编号图、电路图、分布统计、指定网络高亮和三维视图不得各存独立连接真值。修改某层/变换/裁决后标记相关派生结果待重算。

## 能力与 skill 候选边界

| 能力 | 产物 | 验收重点 |
| --- | --- | --- |
| 输入规范化 | 标准照片栈、输入质量报告 | 来源、语义、坐标、可见范围、配准用途 |
| 整体理解与区域规划 | 有编号的粗区域框、类别候选及处理计划 | 分类依据、混合/未知区域、覆盖情况；框不是材料边界 |
| 分层版图复原 | AA/poly/CT/金属/via 几何及未知图 | 与源图一致，保留间隙、孔和遮挡，不擅自补线 |
| 指定点网络追踪 | 跨层连通对象、全部分支与高亮 | 入口正确、接口覆盖、隔离与停止点 |
| 器件与端口识别 | 器件实例、端口、指和组 | 结构依据、端口定位、共享扩散与归并规则 |
| 输出整理与分析 | 器件/网络统计、图表、电路图、证据索引 | 同版本、相互一致、未知和数量口径清楚 |
| 三维展示与重建 | 分层几何及过孔堆叠视图 | 未实测厚度/层高须标示意，不冒充真实截面 |
| 总控 | 阶段调用、定向补查、依赖失效和局部重跑 | 可恢复、可知当前版本及下一动作 |
| 质量复核 | 各阶段报告、问题对象及处理要求 | 确定性脚本检查与 AI/人工物理判断分开 |

器件候选与端口应在网络追踪前初步建立，后与连接结果相互修订；不等待全部金属点亮才识别器件。区域规划同样可被提取结果修订。

质量约定属于每阶段合同；质量复核 skill 可组织检查，但不取代脚本校验或人工裁决。总控先采用轻量记录和既有命令，不提前搭建通用调度平台。skill 数量可按实际重走结果调整，不按表格机械创建空壳。

## 阶段质量门

| 阶段 | 必须检查 | 未通过时 |
| --- | --- | --- |
| 输入 | 可解码、哈希、来源/层名依据、坐标；明确尺度与覆盖未知 | 文件错误阻断；未知尺度允许像素任务；未验收配准阻断该区域精细跨层判断 |
| 区域规划 | 框对应原生位置，类别有依据，保留未知/混合和剩余区域 | 修改分类或追加定向观察，不凭框生成器件真值 |
| 分层复原 | 原图叠图、抽样边界、细间隙/孔/连通结构、未知及有效区 | 修订局部掩膜，保留首次输出与纠正；不以美观或面积一致代替验收 |
| 连通/器件 | 过孔两侧覆盖、端口归属、断点与对极隔离、分支覆盖 | 停止相关确认传播；回查局部几何/配准，不全图盲重跑 |
| 导出 | 对象引用、修订一致、统计口径、证据及未知 | 拒绝误导性完整导出，允许范围明确的局部结果 |

误差预算应在区域和任务确定后结合线宽、间隙与误并风险制定，当前不编造全芯片统一阈值。图像平滑/闭运算等清理不得未经检查改变拓扑。像素重建与后续多边形简化均需保留连接/隔离关系。

## 首批交付及推进顺序

1. 以现有八张图形成输入清单与用途分级，并给出 AI 整体区域划分图；第一份用户可审文档是区域规划，不先扩大整网追踪。
2. 选已审 Q1/Q2 局部，先定义并验证 AA/poly/CT/M1 分层数据样稿。输出掩膜、未知/有效区、对象来源和原图对照；按需要补局部配准。
3. 验收样稿后加入 V1/M2，再用一个端口检验从分层版图驱动追线。v33 为开发回归参考，不是独立盲测。
4. 样稿证明输入/输出合同可用后，再封装输入和分层复原等 skill，并复用昨日金属追踪协议；三维、全图统计和输出扩展随后推进。

近期不要求把整幅八层像素全部提取完才允许局部验证；目标仍是逐步覆盖整个样本。保留原照片全部输入，按区域/层增量验收，避免全图错误积累后才发现。

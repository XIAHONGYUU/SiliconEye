## 重跑 AI 时怎样比较

1. 建新运行目录，记录模型实际标识、提示词原文／哈希、skill 文件哈希、输入包／照片哈希、日期及已接触的历史上下文。只将原图输入包交给观察者；已有上下文无法排除时记为 `context_exposed=true`，不要标盲测。
2. 先冻结 AI 的第一份观察，输出层身份、上下承载的原生路径／端部、替代解释、未知及依据；再让 AI 按 skill 做邻层与设计结构复核，另存修订版。不能把已审坐标直接复制当识别结果，也不能伪造人审 `connection_confirmed=true`。
3. 冻结后评分：每接口记录身份与下／上承载分别 `correct / wrong / unknown`。新对象 ID 不要求与旧字符串相同；先根据来源路径映射到同一物理对象，映射不清记待评，不能判正确。每项任务只有全部接口均正确才为任务通过；未知不作正确。
4. 另列“是否保持数量／边界等未知”“是否凭重叠补连接”“是否反复请求旧批准”；记录第一版→修订版的变化、内部修订次数、必要时新增的人工纠正次数与原因。未知孔数不得与 AI 候选 3×2／5×2 比较后算人工正确率。
5. 在新目录保留观察、评分、证据和命令输出；报告任务通过数／3与接口通过数／5，同时展示错误和未知。不得把两种分母混用，或与 31 条软件测试合并为准确率。

当前没有新 AI 运行成绩；本轮工程回归结果位于 [verification.json](../../benchmarks/conductive-regression-v1/verification.json)。若只修改接续或质量门，工程回归足够；若改变视觉提示、模型、观察策略或 skill 的判断流程，应另做三项原图重跑。本批用于开发回归，后续新区域可检验迁移，陌生芯片才能进一步提供跨芯片证据。

## 两个 skill 分别承诺什么

| 范围 | 金属重建 skill | VIA 重建 skill |
|---|---|---|
| 当前输入 | 本芯片 M1／M2／M3 原图与邻层、声明的局部范围、父包／旧批准 | 本芯片 M1-V1-M2 或 M2-V2-M3，来源窗口、两侧金属和父包 |
| AI 工作 | 判断走向、折线、局部宽度／端部／间隙；提出来源支持的正交几何 | 判断孔层与两侧承载；提出组级支持区或有来源依据的规则阵列 |
| 脚本保证 | 来源绑定、正交／相对次序／转折、配置像素宽度间距、改动白名单、继承检查 | 来源身份、方孔／等尺寸／同层孔距、完整声明阵列包围、审批绑定；代理明确未完整评估 |
| 已验证修订 | 同 ID 的局部路径／宽度／凸出，其他对象与批准不变 | 已显式数组的缩孔保中心；接续人审承载，不将承载批准升级为数量批准 |
| 输出 | 独立设计坐标的局部候选、原图宽／放大证据、质量分项、可接续 manifest | 同一套复核包内的身份、承载、数组／代理资格、未知和 scoped 人审 |

两 skill 复用 `conductive_workflow`，不按 M1／M2／M3 或 V1／V2 分裂实现。当前只能支持 **AI 指挥并复核的工程流程**，不是命令自动识图。来源形状检查针对声明的观察，声明本身若错误仍需回查原图。设计规则使用当前相对设计像素预算，不能称为真实 PDK DRC 或物理尺寸验证。

补建入口现另验证了清单驱动的显式金属扩展：新增22个片段，旧feature/interface逐字段保留；扩展不能新增孔或改变连接。该项只增加工程事务能力，新几何仍待复核，不改变限定试用v2、旧端部部分覆盖与照片穷尽性未知的边界。

共同边界：不保证全幅／所有可见结构已覆盖，不保证精确照片投影、逐孔实测、陌生工艺、M4 以上、完整网表、器件参数、共同 GDS 采用。不能跨独立局部画布拼网络；无孔声明不证明物理无孔／全局异网。V1／V2 投影可重叠；本芯片的来源侧策略不泛化成所有去层拍摄的规则。V1-S1 小支持代理的包围不能替代完整孔组包围。

## 扩大覆盖的放行标准

本轮整理后仍是限定试用，不以通过工程回归自动升级 skill。下一批按一段连续可见走廊做覆盖验证，而非再添加互不相连的小点：

1. **先声明范围和清单**：原生边界、局部设计坐标、可见导体／接口／图外端部清单先冻结，列明未知；区域裁切不能切断导体身份。照片覆盖率只针对这份可见清单计算，不拿旧 38 条批准记录当全图分母。
2. **验证重建与可见证据**：清单内每项有对应候选或明确未知原因，不能静默漏项。完整声明孔组全部通过包围和同层间距；未逐孔分开的支持组保留代理资格。原图上下文单独检查漏排、错承载、镜像转角与不合理拉伸，软件通过不能替代该项。
3. **接续与退化门**：运行固定回归；旧四个局部坐标域的结果不丢失／换 ID／改承载，缩孔不漂中心、局部修订不改变未授权对象，不新增自动连接或采用。老问题原样通过即可，不重复索取旧批准。
4. **分项发布结果**：分别列程序通过、AI 第一版／修订版、已审连接、工作几何、完整阵列／代理、未知及可见清单覆盖；只有影响新身份／承载的真歧义才提交人工。关键未知未解可继续其他项，但不能宣称该项完成。

满足这些条件只能扩大到该连续区域的限定能力。正式扩大到全幅需建立全幅清单与边界交接证据；跨芯片和真实 PDK 资格须独立验证。连续区域可使用既有 R1–R2 两条长 M2 的走廊，先盘点再核对中部交叉、端部与邻线。当前执行进度仅见项目 CURRENT_TASK.md，不由本资格文档维护。

# CT重建工作流：约束生成、联合匹配、硬性导出门

2026-10-20纠偏：以下v1局部亮点试验是历史诊断，不是合格CT重建入口。最新实现和强制导出门见[整改检查点](../checkpoints/2026-10-20-ct-joint-control-repair.md)与[新联合复核页](../assets/ct-joint-reconstruction-v2/index.html)。规则必须参与几何生成，整体失败要阻止重建导出；不能仅输出HOLD再把杂乱亮点交给用户验收。

2026-10-20。继承已锁定的[AA/POLY工作基线](../../benchmarks/poly-closeout-v3/stage-acceptance-v1.json)，不重新提取或移动已审材料。输入照片的CT亮点主要从poly照片观察；层名称不是纯材料掩膜。

## 从POLY阶段继承的方法

1. 先看原图与上下层关系，保留来源坐标。亮点算法只提出观察，不决定归属。
2. 将观测位置投到共同设计坐标；精确落点必须先验证局部对应。全局变换或人工调整过的材料定位框不能自动算精确配准证据。
3. 用正向结构查错：完整孔需被相应材料包围，普通MOS沟道不放接触孔，孔列应有可解释的尺寸/孔距和同组规律。发现冲突先区分投影偏差、孔尺寸假设、材料边界与误检，不移动孔或材料强行过门。
4. AI结合器件、环、电阻端部和CT可见性复核算法观察；有依据才修订。人工只裁决仍影响归属的关键问题，不逐孔重做已审工作。
5. 保存局部修订和前后对照；通过局部质量门才扩展全幅，再考虑skill封装。

## 正向规则如何使用

2026-10-20在线复核[GF180 Contact §7.12](https://gf180mcu-pdk.readthedocs.io/en/latest/physical_verification/design_manual/drm_07_13.html)：CO.1/2检查尺寸与孔距，CO.3/4/6检查材料和M1包围，CO.7/8检查邻栅/扩散距离，CO.10/11限制沟道与场区落孔。仅借鉴这些结构关系，不将其微米值作为本照片工艺数值。

[SKY130 periphery的licon章节](https://skywater-pdk.readthedocs.io/en/main/rules/periphery.html#licon)也规定形状、包围和混合落点限制，并存在长孔及器件例外。其licon连接poly/diff/tap与li，mcon另接li与M1；不能将这些层名直接当成本项目CT的完整路径。

本样本先以正交方孔表达候选，尺寸8相对像素、包围1像素、孔距2像素是明确的试验预算，尚未由工艺或人工确认。方孔合法不等于CT身份正确，也不等于通过真实DRC。未知或特殊器件不套普通MOS禁孔规则自动删除。

| 检查 | 当前行为 | 不能做什么 |
| --- | --- | --- |
| 真实观察支持 | 原紧凑残差亮点＋有两个邻近行/列观察支持的真实亮峰补充 | 按预期孔数生成没有亮峰的孔 |
| 下层包围与沟道 | 检查完整候选方孔；AA/POLY混合或无完整包围保留未知 | 只用中心点包含或选最近材料确认归属 |
| 规则几何 | 检查方孔和声明的相对孔距；保留冲突列表 | 缩孔、删冲突孔来伪造PASS |
| 同组规律 | 未确认局部对应/同一孔列时禁止周期吸附；候选平移预算有限 | 把一个窗口的不同器件孔和环孔混作同一阵列 |
| M1包围 | 当前未测，保持unknown | 仅凭落在AA/POLY上便确认电连接 |
| 接续保护 | 输入与阶段锁定哈希验证，输出后再检查基线哈希 | 用CT试验改写700个POLY或336个AA |

## 本轮局部试验

[复核页](../assets/ct-reconstruction-v1/index.html)有四类窗口：CT01上方小MOS、CT02六条MOS及邻近宽MOS、CT03长条电阻上端与环、CT04竖向环及转角。每处可切换原图、原紧凑形状结果、补充候选和AA/POLY规则图。

降低亮度阈值205→190没有增加观察点，说明该参数调整不足以解释漏检。补充检测放松紧凑形状限制，要求实际局部亮峰和至少两个邻近行/列观察支持；新增点全部保留未知，不据此声称召回率提升。参数集中在[spec](../../benchmarks/ct-reconstruction-v1/spec-v1.json)。

继承全局投影暂未获局部落点验收，当前归属仅是假设，间距冲突亦可能来自投影/尺寸假设。复核页默认显示原图定位，规则图明确标为待配准。先检查投影，再讨论CT归属，不将大量unknown转交用户逐孔裁决。

复现：`.venv/bin/python -m silicon_eye.ct_reconstruction --spec benchmarks/ct-reconstruction-v1/spec-v1.json --output runs/新目录`。输出目录必须不存在。该脚本是确定性候选与检查工具，不是已经实现的自主视觉Agent或已封装skill。

### 对应检查与几何检查必须分开

v2联合几何通过后仍被用户发现整组源图左移一列；亮峰数与暗栅对比不能替代边界器件核对。必须检查首列、末列及相邻宽MOS排除范围。局部修正应支持只替换源观察对应、完全保留合理的设计几何；本轮实现与回归测试见[源图修订](../../benchmarks/ct-source-correspondence-v3/verification-v1.json)。

### CT反馈可以触发受控的POLY局部修订

人工确认共栅或接触引出后，应允许以明确范围、父版本和前后差异修改POLY；既有材料是可接续的工作模型，不是阻止新增证据的永久硬框。保留已审源漏CT及无关材料。AA接触检查AA包围并避开POLY沟道；POLY接触检查POLY包围并避开AA，承载材料不能混用。同一已确认导体的栅指与横带应物理合并，同时保留栅指ID供器件层引用。[本轮实例](../checkpoints/2026-10-20-ct-common-gate.md)。

### 迁移与防退化

新区域需从已锁定材料模型和CT验收记录接续，保持已审完整对象不变；不能仅依靠总孔数相同来证明无退化。通用行列接口以源观察ROI、局部格点、承载材料ID和显式像素预算为参数。多峰与偏离格点的观察留在台账，缺观察不生成接触；局部几何通过仍需独立核对源图边界和材料角色。[迁移实例](../checkpoints/2026-10-20-ct-transfer.md)。

### 峰数不等于完整行数；数量门与几何门分开

局部算法仅看到两排亮峰时，不能把两排当作全阵列行数再拉满承载AA高度。先区分检测到的观察子集与完整孔列假设；AI核对原图、同排相邻器件及阶梯边界，必要时交人工裁决。完整AA列可检查同组共享相位/节距及已确认行数，阶梯边列保留明确例外；不得为了补满数量扩张AA或填入明确非孔位置。

输出门同时记录普通几何检查和依据人工样本的数量/边列/负例检查。两者通过不代表自动识别召回率或真实PDK DRC通过。人工确认仅可替代对应存在/数量判断，不得生成假亮峰；精确原图点仍为估计时须明确标注。接续时旧记录的来源字段保持，设计坐标修订单列台账。[中下部实例](../checkpoints/2026-10-20-ct-lower-middle-mos-revision.md)。

### 来源反例必须作用到整条路径，安全子集与整层状态分开

真实亮峰可以被错误分配到材料。一个源点被不同承载对象引用，或环源路径落到独立可见的栅端亮条，必须先核对材料对应；既有引用也只是需要保护/复核的工作记录，不能仅凭旧ID宣判物理归属。发生来源反例时整条未验收路径暂缓，保留观察；不能删除反例点后继续输出其余点并宣布路径有效。

旧原生POLY框是定位假设，不是照片材料真值。可从已观察栅端反向定位源漏列，或用独立框和实际源漏列校正端部来源；设计几何保持或受控修订，不能靠缩孔/扩AA迁就错误来源。最近距离可加速，但必须以全配对结果和边界条件对照，不能降低孔距/包围门。

安全几何子集的PASS与整层HOLD必须同时写入机器可读模型/报告和人审页面。每个材料有处置状态不等于每个CT已确认；dummy、邻片、截段与紧凑未知AA不能统一补孔。新来源裁决前只导出候选复核包，不发布完整层结论。[本轮实例](../checkpoints/2026-10-20-ct-full-frame-remaining.md)。

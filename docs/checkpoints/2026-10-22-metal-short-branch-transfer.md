# 第二组：短支路接口迁移验证

[复核页](../assets/metal-short-branch-transfer-v1/index.html)支持M1／V1／M2切层、两层宽范围原图、4倍局部与观察线开关。本轮选择历史W1短竖M1与M2短竖下端接口，与第一组宽线规则孔阵列形成不同结构的对照。

这是**已知样本迁移回放，不是新的盲测识别**。历史用户原文为“左图 M2 的下端，通过 V1 接到右图紫框 W1 所在的短竖向 M1”，参见[原裁决](../../benchmarks/metal-extension/roi2-W1-V1-M1-review-feedback-v1.json)。不重新要求用户批准同一接入，也不将历史批准扩大为精确孔位、孔数、边界或整网完成。

## 验证范围

| 检查 | 结果及范围 |
| --- | --- |
| 第一组防退化 | 锁定已审spec／模型／报告／产物清单，保留J1/J2、M1无V1框、M2的V2身份及六处共同层来源限制；前后复跑比较见核验记录 |
| 独立M1几何 | W1短竖、上横线、下横线分别保留ID；最小对象间距9设计像素，无同层误并 |
| M2短支路 | 短竖与可见宽端部为同一导体，形状规则；不把端部亮点自动当成V1 |
| V1承载 | 沿用历史已审端点，6×6像素支持区及2像素包围落在两层金属内 |
| 孔数精度 | 支持区只是孔组的最小示意载体，**不代表物理上只有一个孔**；孔数保持null |
| 模型跨层重叠 | M2与上横M1存在重叠，但没有对应V1证据，不生成新连接；不据此宣称照片已证明该处物理无孔 |
| 来源约束 | 原生W1折线绑定旧M1观察、M2端点绑定旧人工裁决；不能把已审下端移动到宽端部亮点 |

复用既有`geometry_audit`、`feature_polygon`、`interface_audit`及复核页工具；通过新的数据请求指定另一组材料与证据，没有创建W1专用脚本或新skill。不同金属各自检查间距，跨层重叠不能放进“同层短接”门，也不能自行变成电气连接。

## 坐标与验收边界

设计几何放在当前5860×4587共同画布的候选位置。W1的历史M1→POLY定位及当前附近CT记录仅提供导航锚点，未赋予新CT归属、逐像素边界或新AA连接。AA／POLY／CT快照未修改。

M1、M2原生参考点分别为历史记录中的(1244,3220)与(1217,3253)，不是人工实测孔中心。没有独立合格的M1↔M2或原生→设计精确矩阵，因此两张照片并列、不作投影；不能把第一组的小范围拟合外推到W1。

报告状态`KNOWN_EXAMPLE_TRANSFER_VERIFIED_WITH_LIMITATIONS`。本轮验证了既有方法可表达并保护短支路结构；没有测得陌生照片识别准确率、独立配准精度或人工返工减少量。当前无需新增人工裁决；自动网络导出关闭，没有新增物理连接批准。

## 固定反例与恢复

相关37项测试通过（30.95s），包括：

- 第一组原有约束及接入接续；
- 把短M1拉长接入上横线时拒绝输出模型；
- 复制孔支持区、复用同一观察增孔时拒绝；
- 将M2已审下端换到上部亮端时拒绝；
- 原生观察折线与锁定证据不符时拒绝；
- 跨层重叠不生成未经支持的接口。

[输入](../../benchmarks/metal-short-branch-transfer-v1/spec-v1.json)、[模型](../assets/metal-short-branch-transfer-v1/model.json)、[报告](../assets/metal-short-branch-transfer-v1/report.json)、[主Agent核验](../../benchmarks/metal-short-branch-transfer-v1/verification-v1.json)。Ruff、SVG、JS语法、链接与输入／产物哈希核对记录在核验文件；未声称浏览器点击验收。

      导出确认 JSON

      总体意见（可选）

      导出后交给 Agent 接续

      回到对话告诉 Agent“已导出”。本机 Agent 读取对应版本的下载文件，校验后归档并回报结果；如果无法找到文件，再提供 JSON。

      开发者归档命令

      由 Agent 执行：

      python -m silicon_eye.review_sheet check --package <送审包目录> --decision <review-decision.json> --archive --root .

      校验通过后会写入同类固定文件 review-decision.json 和 review-record.md；不会覆盖不同的既有记录。

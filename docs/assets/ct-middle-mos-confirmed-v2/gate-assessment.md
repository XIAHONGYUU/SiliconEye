# 中部MOS栅极／栅端CT诊断

2026-10-20。用户补充：此前48处橙色虚框可认为CT，同时要求评估栅极未可靠辨认的原因。

## 首先纠正问题定义

Q2的30条栅极主体已经在既有POLY模型表达；此前没有可靠完成的是“栅端CT及其引出关系”。不能将二者混为“栅极都没识别”。此前说“栅端CT尚未可靠辨认”属于状态描述，但把原因归给图像难辨并不充分，流程未覆盖是首要问题。

## 可核验的原因

1. **检测范围没有覆盖栅端CT。** 上一版spec的51条profile_rows全部material=AA、target为AA扩散或环；没有一条面向POLY端部，也未调用共栅/栅端孔专项拟合。本轮输出630源漏＋356环，新增POLY接触为0。因此空输出不构成“找过但找不到”的证据。
2. **现有POLY模型给的是主体及候选端部，不是精确接触区。** Q2共30条记录，kind=MOS_gate_body_candidate、terminal_status=material_endcap_candidate_not_CT_assignment。其端部采用8个相对设计像素的延伸参数；原图四边形是derived_photo_locator_from_recorded_AA_projection_not_precise_source_boundary。它们不能直接当成栅接触中心、已确认引出或共栅连接证据。
3. **单看亮度峰容易混淆端部边缘与孔。** GA/GC纯原图中，源漏CT有明显重复点列，而栅端附近同时存在连续亮边、材料边缘和底部环的孔列。当前观察不足以把某一个点明确归为POLY CT，但也不证明图像无法辨认或没有栅CT。48处已确认虚框全部属于AA扩散/环检查槽位，不会自动成为栅CT。
4. **专项证据不完整。** GA、GC是下端细看图，A/B/C完整视图用于源漏/环对应；尚未逐栅检查上下端和侧向延伸，也没有以真实配准的M1局部结构反查。因此尚不能判断引出在何处，或是否经其他POLY段连接。不能套用邻近RIGHT6的共栅和孔数。

以上1、2、4来自参数和模型检查；第3条为本次原图视觉观察。光学反射/遮挡可能有影响，但未量化，不列为已证明的主要原因。

## 正确的下一步

以已审AA/POLY主体为起点，单独列出30条栅的端部与侧向延伸检查范围，覆盖上下端；先核实照片中的实际POLY连续范围，再对候选CT做材料归属。必要时使用具有可靠局部对应的M1作为交叉证据，不能盲投影。对具体疑点提供上下层和足够大的上下文，仅由人裁决确实不清楚的位置。

在专项检查完成之前，保留“栅端CT未知”；不把AA边缘孔因靠近POLY改判为栅CT，不因MOS应有栅极连接就自动补孔，也不改变已批准AA/源漏/环CT几何。

# 金属网络点亮流程 v1：2026-10-17 复盘与重走约定

本稿固化用户与 Agent 对本轮经验的共同复盘。它是待重走检验的工作约定，不代表自动金属提取、运行时视觉 Agent 或 skill 已实现。现有工具可生成复核图、适配观察记录及保存状态；跨层判断仍由 AI 与人工协作完成。

## 输入、输出与当前基准

输入是同一位置的多层原始照片，各层使用独立的原生像素坐标。原图不可改；配准变换和派生标注另存。只处理任务需要的相邻层与局部区域，不要求先完成全部八层精确配准。

输出至少包含：各层金属点亮图、连接摘要、带来源的连接记录、已检查与待查分支、端点及照片边界说明。参考中心线、材料身份、精确边界、电气连通性分别记录，不因一次批准全部升级。

## 执行顺序与检查点

1. **确认目标端口和初始接入。** 确认器件端口→CT→M1→首个跨层接口，之后才扩展。旧 gate 选错后，后续金属关系可自洽却属于另一网络，说明起点必须单独核对。
2. **先局部对齐，再投影。** 周围重复线列、环或其他可对应结构用于定位与拟合；另用未参与拟合的对应结构检查。记录变换方向、来源和有效范围。M1 的 V1 应落在相应 M2 覆盖内，但不能仅为连上目标而调整变换。残差小不证明身份对应正确；误差需结合线间距和误并风险判断。超出局部有效范围重新核对，不能外推全图。
3. **识别整段连续导体。** 沿完整可见范围检查端部、转折和中段接口，不把进入点附近的一小段等同于整根金属。器件端点、断点、照片边缘与不确定延伸分别记录。
4. **循环检查所有上下层接口。** 使用待查分支清单：取一根导体→检查所有适用的上下层接口→加入新导体→标记已检查范围→继续，直到清单处理完或遇到明确歧义。不是只上行一次再下行一次。N04 的五处 M2 必须全部展开；进入 N04 的 T 仍需检查其下接 M1，不能因它是来路而漏掉。
5. **用正向版图思维解释结构。** 根据母线、梳齿、重复阵列、间距及上下层布局提出可能的绘制方式，主动寻找验证和反证。推测可引导检查，但不能仅凭电路常识确认连接。记录解释与实际像素证据的区别。
6. **按连接关系控制粒度。** 一列 CT 若足以支持同一端口接入，可作为接入组，不要求逐孔确认数量和轮廓。CT 接 AA 还是 poly 必须分清。V1/V2 需查看对应来源层，不能只凭上层亮点猜层别。
7. **在器件端口停止直接导通扩展。** 不穿越 MOS 沟道或电容介质；绿色梳齿与橙色母线虽交叠仍保持两极隔离。多层同电极连接需有相应接口依据。
8. **最小化人工裁决。** 提供原图位置、足够宽的放大图、经核对的叠图、稳定编号和一致颜色；标线不遮关键孔。只询问会改变网络的未决问题，复用已确认结论。
9. **按依赖纠错。** 分开记录物理连接与目标网络归属。撤销错误 gate 入口不抹掉已确认物理子图；配准变动后只重查受影响接口。保留原记录和纠偏原因，不覆盖历史批准。
10. **按范围验收。** 检查每根已识别导体的沿途接口、全部新增分支、端点及隔离关系。区分已确认、AI 候选、冲突、未知。已识别可见分支完成不等于完整芯片无遗漏；没有发现新孔也不等于证明无孔。

## AI、脚本与人工的分工

| 工作 | 主要负责方 | 交付或约束 |
| --- | --- | --- |
| 导体身份、连续性、结构解释、寻找遗漏与反证 | AI | 保留来源、候选解释和不确定性 |
| 坐标变换、裁图叠图、来源哈希、关系整理、待查清单检查 | 脚本 | 固定执行可重复，不以 PASS 代替物理真值 |
| 改变网络归属的关键歧义 | 人工 | 明确批准对象与范围，避免逐 CT 审批 |

上述为职责约定；当前尚无自动维护整网待查清单的通用追踪器。本轮仍使用伴随 JSON 和人工/Agent 检查。

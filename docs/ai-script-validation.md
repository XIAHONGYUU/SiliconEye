# AI、脚本与人工分工及验证设计

2026-10-13：用户已确认先完成本设计，再开始配准实现。本文是项目设计约定；实时进度仅在 CURRENT_TASK.md。

## 原则

脚本负责固定流程、精确计算、状态管理和可重复验证。视觉模型负责分割与识别；多模态推理模型负责综合证据、提出解释、选取回查位置。人工负责基准标注、缺失物理事实与关键冲突裁决。

AI 由脚本调用仍是 AI 处理。开发时 AI 写代码与运行时 AI 分析版图分开记录。稳定且有证据支持的判断可以沉淀为脚本规则；模糊判断引入模型不等于自动获得正确答案。

## 阶段职责

| 阶段 | 脚本 | AI | 人工与接受条件 |
|---|---|---|---|
| 输入/预处理 | 校验、源图哈希、裁剪、坐标转换、派生图保存 | 识别模糊、残留及异常，建议处理区域 | 确认输入来源；源图不变 |
| 配准 | ECC/ORB、变换、有效像素掩膜、叠加图、指标 | 选对应结构和 ROI，检查局部错位、提出重试建议 | 复核参考结构；算法成功不直接确认为真实对齐 |
| 层/区域理解 | 管理层序、坐标、已确认标签 | 提出层语义、器件/功能区域候选 | 确认去层顺序、工艺和尺度来源 |
| 分割 | 调用模型、处理掩膜、轮廓与几何 | 视觉分割；选择提示、样例与歧义解释 | 对照独立掩膜基准 |
| 器件识别 | 计算交叠/间距/重复模式、工艺约束检查 | 综合多层证据分类、多指/候选分组 | 对照器件基准；无依据时保留未知 |
| 尺寸/端子 | 在确认边界上量测，应用已确认尺度 | 提出边界角色及端子候选 | 尺度未知时只报告像素，不宣称物理 W/L |
| 连线 | 从确认的导体/via 构建图，检查冲突 | 提出断裂、残留及跨层对应的解释 | 对照人工连接；不得凭电路常识补造连接 |
| 清理/电路理解 | 拓扑搜索、比例计算、规则验证、可逆修改 | 提出差分对、电流镜、dummy 等解释 | 尺寸相似仅产生候选；删器件/合并需连接证据 |
| 输出/验收 | SPICE 导出、节点端子检查、适用仿真、审计记录 | 整体合理性检查和回查建议 | 导出/仿真成功不等于逆向正确 |

## 判断接口（设计合同，后续按阶段实现）

每个判断记录包含：

- `id`, `stage`, `source_ids`：唯一对象/判断 ID、阶段、输入来源。
- `roi`：源图像素坐标的 x/y/w/h，图像 ID、裁剪/缩放/变换引用。物理尺度另存来源，不混用坐标系。
- `producer`：script / vision_model / reasoning_model / human；算法版本或模型标识、提示版本、运行 ID。
- `proposal`：候选类别、结构、连接或变换建议；可保留多个替代解释。
- `evidence_refs`：图像区域、掩膜、端子、导体、数值检查等可定位证据。
- `uncertainty`：缺失事实、替代解释、回查建议；模型置信度与实测指标分别存放。
- `checks`：脚本检查 ID、结果、阈值及其适用范围。
- `status`：candidate / confirmed / conflict / unknown。
- `decision`：接受/拒绝/待处理理由、裁决者、时间及前一版本引用。

AI 输出先进入 candidate；结构化格式通过不等于 confirmed。脚本能确认明确几何事实；真实层语义、模糊连接和删除/合并依据需对应阶段的基准或人工裁决。冲突进入 conflict，缺证据进入 unknown。重试保留历史，不覆盖旧结论；下游保留状态及依赖证据，不能将未确认项悄悄变成事实。

## 配准核心接口（本轮实现）

- 输入：uint8 灰度 H×W 或 BGR H×W×3，参考图与目标图，method 和 ORB 参数。显式 ECC 要求同尺寸；ORB 可处理不同尺寸；auto 不同尺寸时跳过 ECC。
- 统一矩阵方向：目标像素 → 参考像素；坐标顺序 x/y。ECC 当前只求平移；similarity / affine / homography 参数用于 ORB。
- 输出：`warped`, `matrix`, `matrix_direction`, `method`, `success`, `reason`, `num_matches`, `inlier_ratio`, `rmse`, `correlation`, `valid_mask`。
- 成功图保持目标图的灰度/彩色与 dtype，空间尺寸等于参考图；valid_mask 标记完全有效的重采样范围，填充像素不能参与验收。
- ECC 报告实际 correlation；没有关键点的 rmse / inlier_ratio 用 None。ORB 的 rmse 是 RANSAC 内点重投影距离的均方根，单位 px，包含透视除法；它不是独立基准误差。
- 预期算法失败返回 success=false 和 reason，warped 为未变换目标副本，valid_mask 全 false；identity matrix 是占位，不是测量结果。参数/输入错误抛 ValueError。auto 的失败/回退原因保留在 attempts。
- 该接口只执行脚本职责。AI 的参考区域建议与真实图复核尚未接入；不得据此声称已完成运行时 AI 协同。

## 三层验证

### 1. 合成图回归（本轮）

固定种子生成有纹理的小图，保留真实变换。覆盖正负位移、ECC/ORB、similarity/affine/homography、彩色保存、不同尺寸、空白图、匹配不足、短近邻列表、估计失败、非法输入及 auto 回退。

已知变换在独立网格点上的恢复误差 ≤1 px；同层合成图内部区域对齐后的灰度 RMSE 至少下降 50%。验证输入未变、有效掩膜、失败语义和指标定义。此门槛只适用于固定合成图，不直接外推真实跨层照片。

### 2. 真实照片配准（下一任务）

源图保持不变，保存输入哈希、代码版本、参数、原始/叠加/局部图、矩阵和失败原因。人工标注分散且可对应的结构；用于选参数的点与用于验收的保留点分开。报告保留点误差中位数/P95/最大值、覆盖范围及未知区域。

按最小关键结构尺寸设置误差预算，并在正式比较前固定。未确认尺度时用 px。跨层亮度差异和 ECC correlation 不作为独立几何真值。重复纹理即使分数高也需要复核；没有可靠对应结构的层可标为 unknown，不能强制通过。

### 3. AI 增益验证（完成真实图入口与人工基准后）

在同一批保留 ROI 上比较 A：脚本基线，B：脚本+视觉模型，C：脚本+视觉模型+推理复核。相同原图/基准/资源约束，固定模型、提示和参数；用于调参的 ROI 不进入最终评估。同一芯片相邻裁剪不宣称跨芯片泛化。

- 几何：独立关键点误差；分割：IoU、边界误差；器件：precision/recall、类型准确率、尺寸误差。
- 连接：误连/漏连数量和边准确率；另报告未知/拒答比例，不能通过大量拒答虚增准确率。
- 工作量：每区域人工修正次数、分钟数；成本：运行时间、峰值资源、模型调用成本。
- 推理稳定性：同一区域至少三次运行，记录结论和关键连接变化；保留全部运行，不挑最好一次。
- 初始接受规则：关键误连不得增加；保留集准确性不下降；人工修正时间下降才证明当前阶段的 AI 增益。阈值和样本量在正式比较前锁定，探索性小样本结论不得外推。

人工保留基准优先于模型置信度。测量同一计算的脚本自检与 AI 重复相同结论不算独立验证。

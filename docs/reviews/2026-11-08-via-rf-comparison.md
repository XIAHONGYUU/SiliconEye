## 同条件结果

同一M1照片中，训练4个区域（2真孔、2假目标）；测试另7个不重叠80×128裁片（4真、3假）。按物理区域分割，匿名测试，训练参数与AI像素涂画在预测前冻结。视觉执行Agent为无历史上下文的新Agent。原始算法标注阶段继承部分历史对话，但仅读公开训练图；后续执行Agent也使用新上下文且只载入冻结参数，未读测试答案或按测试结果调参。

| 指标 | AI直接视觉判断 | ilastik像素随机森林 |
|---|---:|---:|
| 已审真目标命中 | 4/4 | 4/4 |
| 已审假目标误报 | 0/3 | 1/3 |
| 假目标仅保留unknown | 1 | 0 |
| 假目标框内无候选 | 2 | 2 |
| 所有候选框（含unknown） | 5 | 23 |
| 已审范围外候选，尚未裁决 | 0 | 12（5 via、7 unknown） |

孔命中仅要求合规候选中心落在已审目标范围，是粗定位，不是精确孔位/孔数/像素分割准确率。无候选不等于明确确认非孔。不同分支候选分组粒度不同，23对5不能直接折算工作量；12个框外候选确实需要另行核查，不能算作已确认误报或忽略它们。

Q03（历史U2）是确定的假目标：视觉保留unknown，RF在其范围内给出score=0.786875的via候选。RF在Q03和Q06也同时有unknown候选，因此不确定性显示并未阻止Q03的假阳性；score和像素熵不是校准后的物理真实性概率。

## 解释与下一步

这次没有证据说明“随机森林对孔检测无用”：它已用很少训练资料自动命中4处保留真目标，并且可快速重复应用。也不能说明它优于现有视觉判断：误报与额外候选尚未带来可量化的审核时间收益。

从图上看，RF会把部分亮条纹/亮带局部作为孔外观；这与少量训练下的像素分类局限一致，但尚无消融试验证明唯一原因。范围外候选不能据此直接判假。下一轮应补充类似U2的困难负样本、另留全新物理区域测试，并计量“预测+人工复核/修正”总时间；不能在本次7张图上改阈值再称独立验证。当前仅建议受监督候选预筛，不自动采用身份/连接。

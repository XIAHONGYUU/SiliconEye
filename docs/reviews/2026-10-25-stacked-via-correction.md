# V1/V2投影重叠修订

用户反馈：Q1的V1范围基本合适，但V1/V2应有投影重叠；Q2的六个V2基本占满M2，与V1也应重叠。原文分别保存在[q1反馈](../../benchmarks/stacked-via-review-v2/q1-human-feedback-v1.json)与[q2反馈](../../benchmarks/stacked-via-review-v2/q2-human-feedback-v1.json)，均绑定当时送审包。定性范围认可、数量、具体新坐标分别记录；没有新增连接审批，也不把新候选坐标写成人工已批准。

## 根因与规则

代码核查确认：中样和统一观察入口的孔组间距门均按V1、V2分别循环；单接口检查只处理一个孔层。此前没有“禁止V1/V2投影重叠”的硬规则。问题在AI候选独立摆放、照搬6px演示孔径和不准确的金属比例，导致两组被错开，且Q2孔组相对M2明显过小。

同一层孔不能重叠且必须满足间距；不同高度的V1与V2可以投影重叠，分别检查M1/V1/M2、M2/V2/M3的包围。[GF180官方手册7.14](https://gf180mcu-pdk.readthedocs.io/en/latest/physical_verification/design_manual/drm_07_15.html)的Vn.5允许叠孔，其注2用相邻孔层的投影相交定义stack。此引用用于核对结构概念，不用于认定本芯片工艺、套用GF180具体微米尺寸或宣称DRC通过。

“不同物理孔、不能作为同孔配准”不意味着“版图中必须错开”。本轮不复活已撤回的V1/V2同孔拟合，不把不同照片的原生坐标直接投影。

## 共用流程与显示

新增组级`geometry_parameters`只调整有来源依据的局部cut_size/pitch，不能修改全局最小宽度、间距或包围。所有孔仍为方形、组内等尺寸、等节距。照片支持的候选尺寸不再被演示参数6px固定；局部画布参数不当成真实工艺孔径。两套样本仍走同一个workflow、阵列生成和绘图工具，没有增加案例专用提取程序。

补充`via_group_geometry_feedback`绑定旧送审请求和来源身份；其孔数可进入`observed_group_count_facts`，不替换已有连接审批，也不批准新几何。错误照片、承载或接口绑定会拒绝。

复核入口使用透明叠加、轮廓、逐层开关、新旧同坐标比较及孔组局部放大，避免上层遮挡下层而误以为缺孔。来源宽图和完整放大图复用既有24视图，原始照片不改。本轮两个skill和统一契约已同步这条分层检查原则。

101项相关回归、47项底层/旧导体回归通过，补充1项孔数反馈错承载测试也通过，共149个不同测试；重跑8项本轮用例不重复计数。覆盖：跨层完全重合可通过、同层切孔/孔组重叠拒绝、局部尺寸不能降低硬规则、Q1金属/V1完整保持、Q2已审连接/V1不变、六孔事实绑定正确接口。

Ruff、两个skill格式和git diff检查通过；当前交付与重放结果一致，168项包输入哈希、8项交付哈希及全部来源裁片像素核对。71条本地链接、3段JS语法、10份SVG/XML通过。未测试真实浏览器交互、未知芯片或真实工艺DRC。

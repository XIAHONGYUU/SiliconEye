## 完整性如何验证

新增通用台账入口，复用已有 `conductive_workflow.prepare`、`Inputs` 与原图裁片，不新增此案例专用执行脚本：

```bash
.venv/bin/python -m silicon_eye.conductive_inventory \
  --inventory benchmarks/conductive-corridor-inventory-v1/inventory.json \
  --output runs/新的走廊清单复核
```

检查来源哈希及原图裁片像素、检查块是否无缝覆盖声明窗口、每个登记项是否进入检查块、每条 M2 是否有全段接口巡查、出界端部是否正确记账，以及旧模型完整接续和四条审批不变。渲染页复用旧 raw PNG，不复制图像；大字列表可选对象、切层、切上中下段、关闭彩线、放大。

**这只能验证台账自洽。** 软件不执行视觉识别；如果一条真实线从清单和所有引用同时漏掉，脚本不会自动看出来。测试明确覆盖了这个限制：台账仍可通过，但穷尽性保持 `AI_SCANNED_NOT_INDEPENDENTLY_VERIFIED`，照片覆盖率为 null，几何覆盖为 INCOMPLETE。不能声称已经通过独立物理穷尽性验收。

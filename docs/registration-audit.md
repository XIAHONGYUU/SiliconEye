# 八层真实照片配准验收入口

2026-10-13：本机入口已建立并实际运行。此文记录命令、证据解释及本次结果；实时下一步仅在 CURRENT_TASK.md。

## 重跑命令

从实际仓库根目录运行，输出目录必须是新目录，不覆盖旧证据包：

```bash
source .venv/bin/activate
silicon-eye register \
  -c configs/test_chip.yaml --data-root data \
  --reference aa --fit-roi 100 200 5400 2200 \
  --points benchmarks/registration-points-v1.json \
  --method orb --transform-type similarity --max-dimension 1600 \
  -o runs/registration-aa-next
```

`--fit-roi` 是原图 x/y/width/height。拟合只读取该区域并缩小至最长边 1600 px。验证点及其排除半径必须在拟合 ROI 外，参考/目标两侧都会检查；误差由原图坐标计算。

`--points` 可省略，此时生成证据与待复核网格局部图，逐层验收保持 unknown。`--method` 支持 orb/ecc/auto，`--transform-type` 是 ORB 模型。参考层、ROI 和参数是实验选择，未作为用户确认的物理事实。

`--threshold-px` 是运行前锁定的原图误差预算，当前没有可信的最小结构尺度，因此本次不设置。不要根据跑出的误差反推门槛。即使设置预算，未复核点或不足六点/三个图像象限的覆盖也不能判通过。

## 证据包

本机本次结果：[report.md](../runs/registration-aa-v3/report.md)、[manifest.json](../runs/registration-aa-v3/manifest.json)、[AI 目视复核](../runs/registration-aa-v3/visual-review.json)。派生 runs/ 输出被 Git 忽略；工具、测试、点清单及本记录由仓库管理。

- manifest.json：八层源图路径/尺寸/哈希、参数、代码指纹、版本环境、逐层算法与验收状态。逐层写入，中断时保留 running，不能当作 complete。
- source-snapshot/：当前未提交的验收模块、CLI、配准核心及顶层配置副本；Git HEAD 用于恢复其他未改动代码。源图未复制或修改。
- points.json：本次点清单副本。输入点文件指纹另存 manifest；benchmark 清单绑定照片 SHA-256。
- reference.jpg：参考层缩小预览。
- 每层 transform.json：拟合及原图矩阵、坐标转换、拟合指标/单位、有效范围比例、独立点残差、P95 和覆盖。
- original_preview.jpg / before_overlay.jpg：目标原图预览及恒等坐标下叠加。
- 算法成功时才输出 aligned_preview.jpg / after_overlay.jpg / valid_mask_preview.png；失败不伪造变换或输出“对齐成功图”。
- local-*.jpg：四栏分别为参考点原图、目标点原图、配准前及配准后叠加。局部是 256 × 256 原图像素裁剪，黑色可包含越界填充。黄色为参考/原始标注中心；第四栏品红为变换后的目标点，若落在裁剪外则不绘制。

叠加图红色为参考灰度，青色为目标灰度，不同物理层亮度/材料差异本来就存在。不能直接把颜色差异当作几何误差。缩小预览用于整体查看，不能据此声称亚像素准确。

ORB rmse 的单位是缩小拟合图像素；独立点误差的单位是原图参考像素。两者不能混用。本次没有运行模型服务，AI 判断来自本轮对源图及派生图的目视分析。

## 本次独立点与结果

在任何拟合前，从原始坐标网格图中选取 sub、implant、poly、m1 各六个下部结构中心，共 24 个候选对应点。源文件为 benchmarks/registration-points-v1.json，记录 producer、结构描述、排除半径及约 10–30 px 的粗标注不确定性。点均不参与拟合，也未用它们调参数。

这些是 AI 候选点，不是人工真值；物理层之间的外观差异可能移动表观中心。覆盖限于左下小区域，不能代表全图。m2/m3/m4 暂无可靠对应结构，明确保留未知。aa 是参考层，恒等变换不算跨层验收通过。

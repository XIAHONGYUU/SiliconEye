# 开发计划与阶段验收

本文件只维护阶段顺序、依赖和验收条件；实时进度与唯一下一步见[CURRENT_TASK.md](../CURRENT_TASK.md)。[2026-10-26前版本完整归档](history/development-plan-before-2026-10-26-conductive-handoff.md)。

## 总体路线

以同一位置、带层名和原生坐标的多层照片为输入，在独立设计坐标中重建规则几何，再形成导体/器件/端口关联及可追溯输出。照片证据、工作几何和已审电气事实分别保存；材料层重建不以器件观察框切断全幅范围。

| 阶段 | 进入条件 | 输出与质量门 |
| --- | --- | --- |
| 输入标准化与结构对应 | 原图、层名、可见范围及来源已登记 | 原图不改；有效范围、原生坐标和变换资格分别记录；结构未核准不作精确投影 |
| 全局区域理解 | 同位置照片可对照 | 器件/互连/dummy/环/未知观察及评测参考，不充当分层切块边界 |
| AA / POLY / CT重建 | 依赖层的已审范围与未知有明确版本 | 正交规则几何、相邻层相对关系、环/间隔/端部和CT归属；局部修订不退化既有结果 |
| 金属 / VIA联合重建 | 同一局部上下层有结构对应与明确来源策略 | 先源身份及上下承载，再规则孔组、落点、同层间距与完整设计组包围；物理孔数、尺寸与摄影精确映射单独验收 |
| 连续范围迁移与覆盖 | 小样能力已界定，旧批准可接续 | 全部可见片段/接口清单、候选或未知的一一映射、出界端部；清单自洽不等于照片穷尽 |
| 网络与器件关联 | 相应连接及端子有来源证据 | 稳定导体/net/cell/端口ID、同网高亮、照片外出口及未知；不能由重叠自动制造连接 |
| 电路与分析输出 | 器件和连接达到对应输出的证据要求 | 电路图、编号、分布/数量及复核包；尺度/模型缺失时不宣称准确W/L、阻值或可仿真性 |
| skill限定与迁移验证 | 接续、改善、防退化及真实任务复核有证据 | 固定回归、能力范围与失败条件；软件测试与Agent识图评测分别报告，局部通过不冒充全层/陌生芯片能力 |

三维重建和完整网表自动恢复按证据与需求逐步展开，不建立空模块或先行调度框架。

## 各阶段共同要求

1. 默认复用既有成果、稳定ID、人审与未知；不因引入算法或换层从头重提、重新整图人审。
2. AI负责来源判断、上下文/结构解释及候选；算法按具体问题辅助，脚本负责固定执行与一致性验证。目标是提升质量，不能以更快或更自动抵消质量下降。
3. 重建几何服从有来源支持的正向设计结构：正交、阵列规律、环/隔离、孔可落位置及上下承载。真实工艺不明时，通用结构检查不能冒充PDK DRC。
4. 局部修订列明父包、变化ID及依据；保留原生锚点，检查前后差异和不退化。金属补建、接口补建及修改旧几何分为明确事务。
5. 只将影响身份/承载的新歧义交人工裁决；不重复索取旧批准，不逐孔审批代替连接判断。连接批准不自动批准孔数或新坐标。
6. 输出统一分层复核页、模型、来源manifest、质量报告和可接续请求；采用资格、来源不确定性和软件执行PASS分别呈现。

# 局部器件组：统一裁决与导出入口

```bash
.venv/bin/silicon-eye annotate block \
  --spec benchmarks/block-case-v1-v3.json \
  --root . \
  -o runs/block-state-v3-next
```

在仓库根运行；输出必须是新目录。`--root`显式指定sources中路径的根，不根据参数文件的目录层数猜测。
此入口不调用视觉模型或识别新器件，不代替已有的材料/配准工具，也不触发清理、SPICE或仿真。

## 输入和状态

`benchmarks/block-case-v1-v3.json`是从已有记录规范化的数据适配，不是新人工批准。
候选与裁决通过case中的claim/event绑定原反馈、原文摘录和SHA-256；自然语言含义的规范化仍需人工/AI审查，脚本不会自动理解用户回复。
实体、命题、几何、裁决分别保留状态；MOS列G/A/B/Bulk，A/B不指派源漏，当前v1仅支持未知类型、体端位置及像素几何代理。

每次读取指定案例修订，验证十项声明来源、图像尺寸、原文摘录、引用、事件登记和显式替代无环后，从头重算。
只确认same_net生成同网闭包；身份、物理区域共享、局部poly不连、端子金属关联不隐式并网。
no_evidence仍为unknown；different_net必须有明确同范围裁决。

本入口把“最新”限定为当前清单登记的修订。更新反馈需增加来源/命题/事件、明确替代关系并同步inventory和revision；没有目录扫描，也无法猜测未登记的新文件。
旧`annotate networks`、`upper_routing_review`及原历史参数继续保留旧行为，不会偷偷消费此契约。

## 统一输出

| 文件 | 内容 |
| --- | --- |
| resolved-state.json | 唯一状态、有效/被替代事件、来源、坐标、确认分量、未知、冲突与验收标志 |
| local-schematic.svg/png | 只根据状态绘制，含同一state_id；绿色为已复核同网/局部映射，黄色为未知 |
| terminals.csv | 同一状态的四端、金属关联与确认分量 |
| connection-matrix.csv | self / K（确认同网）/ D（明确隔离）/ ?（未知），每行携带state_id |
| report.md | 同状态的图、端子表及逐命题结果，明确布尔命题值和范围 |
| manifest.json | 输入、代码、登记清单摘要、来源核验与各输出哈希 |

C001等是通用确认分量编号，Txxx是未与其他端子确认同网的端点展示名，不宣称不同分量互相隔离。
V3本轮C001成员对应旧标号N3_GM；其余名称变化仅为展示，不是变更接线。
两个体端仍分别是未分配端点，不能因都写null/unknown而合并。

当前重放结果：[runs/block-state-v3-v1r4/report.md](../runs/block-state-v3-v1r4/report.md)。
这些本机输出不替代[已提交的V3物理复核快照](checkpoints/2026-10-16-v3-reviewed.md)。

## 失败和适用范围

来源缺失/哈希漂移、缺少MOS端子、越界几何、类型/范围错误、未登记事件、跨命题替代或替代成环会失败，不创建正常输出。
并行裁决或同网传递闭包与隔离约束冲突时，只保存冲突状态和报告，CLI返回2，不生成正常电路图/CSV。
已有目录拒绝覆盖。撤回同网后重新计算分量，因此可以拆除旧合并，而非只在旧结果上做union。

v1不判定完整物理边界、不支持已知N/P或真实尺寸模型导出；局部拓扑、四端完整及仿真标志保守保持false。
结构状态ready只表示可供复核，不能据此认定新区域或整芯片逆向正确。
历史反馈内嵌的旧runs引用作为原记录保留；这里只校验案例明确登记的来源与范围，不宣称恢复所有历史照片衍生过程。

## 本轮验证（2026-10-16）

- 全套179项测试通过，相关Ruff通过；新增15项覆盖裁决替代/撤回、无证据保留未知、传递冲突、范围、源漂移和同状态输出。
- 反转实体/命题/事件、关系成员及证据列表的顺序，结果与state_id不变；重命名全部实体/命题/事件ID不需要增加案例代码。
- V3同网矩阵按稳定端子ID逐项对照旧快照一致；四个同网端子、两处M1映射、两个未知体端正确保留。
- 只复制案例明确列出的输入到临时根（不提供旧runs），可得到相同状态；这是数据重放验证，不是新的物理图像识别或第二ROI验证。

下一阶段按相同契约选取未参与调参的小ROI；如果必须给通用状态/绘图增加ROI名字，视为复用验收未通过。

配准/材料与同状态电路的联合导出见[统一复核包入口](review-package.md)。

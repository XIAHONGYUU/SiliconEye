# 公开逐层去层照片筛选 v1

日期：2026-10-15。用途：本机工作流设计候选；不作为训练授权、人工材料真值或本项目配准验收通过的证明。

## 首选：同一颗 Motorola 68A00P

来源：[作者图像页](https://visual6502.org/images/pages/Motorola_6800_die_shots.html)。作者明确说明这些照片展示 single 6800 chip 的去层过程，并已相互对齐。由 Greg James 去封装、去层及拍照，Christian Sattler 校正拼接。作者叙述支持“同一物理芯片”，而非仅凭同尺寸、同型号或算法可配准推断。

| 原文件阶段 | 作者说明 | 本轮选择与用途 |
|---|---|---|
| 1a_bf | 去封装后表面；金属仍在，存在制样损伤 | 主样本：金属与下层遮挡对照 |
| 2b_bf | 去金属，部分钝化保留，poly受到较少损伤 | 预览保留，后续可补高分辨率作为poly辅助证据 |
| 2c_bf | 进一步去钝化；poly已受一定侵蚀；明场 | 主样本：可见poly与扩散区交叉关系候选 |
| 2c_df | 与2c同阶段、暗场照明 | 辅助预览，不计为另一个材料层 |
| 2d_bf | 去除剩余上层后，暴露扩散区及接触蚀刻痕迹 | 主样本：扩散区边界和接触痕迹候选 |

五张1200宽预览及三个选定阶段6500宽下载文件均保留源字节；实际尺寸、下载URL、字节数及SHA-256以本机manifest为准。作者提及的10672×10309是其全分辨率拼接尺寸，不等同于页面6500w文件。本轮不声称获得原始显微镜分块数据。

## 使用边界

1. 作者已对齐的图适合跨层材料与拓扑流程设计；不能用它们证明我们处理手拍未配准照片的算法已通过。后续需独立对应点误差；人工施加已知变换仅验证几何回归。
2. 1a/2c/2d是制样状态，不是纯metal/poly/AA三张材料mask。可见颜色不能直接转换为材料标签；2d的接触痕迹不等同于未损伤CT的独立真值。
3. 同一局部多阶段图片是关联样本。训练/验证分割应按芯片或有隔离带的空间区域，不能将同一区域不同阶段随机拆开后宣称独立验收。
4. 本轮只筛选和本机检查。照片的具体模型训练与再发布授权尚未核实，不进入训练或GitHub图片发布。
5. 旧工艺NMOS和当前手拍芯片的工艺、制样及成像不同；用于建立明确流程，仍保留当前芯片作为目标场景验证。

## 本轮排除

- REFICS是合成SEM，不作为同一物理芯片去层照片的证据。
- 真实M1/M2 SEM数据集可用于金属分割基准，但不含所需AA/poly，也未在本轮核实可重建跨层空间对应，因此暂不混入这组三阶段图。
- SiliconPr0n需逐样本检查s1/s2等样品号；同型号与能对齐不足以单独证明同一颗实体。

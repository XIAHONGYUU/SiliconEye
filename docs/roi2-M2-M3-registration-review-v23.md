# M2/M3局部配准候选与M3编号

按“先对准，再标M3”的要求生成局部叠图，并在M3原生坐标中为附近十条细金属编号L01-L10。原始输入不变，单位px；不是全芯片M3提取。

采用已审A/C/E/F物理接口的历史原生参考坐标拟合仿射，S1/S2不参与拟合。四点拟合残差4.89/5.07/6.56/6.39px；留一验证20.35..27.27px，超过细金属辨线所需精度，故只能交付配准候选，未通过正式配准验收。历史物理对应已审不意味着参考像素坐标精确，不用训练残差冒充真实精度。

[候选叠图](../runs/roi2-M2-M3-registration-v23/M2-M3-local-overlay-review.png)左上为M3原图，右上M2红/M3青，下部为同一候选的局部放大；[参数及检查](../benchmarks/metal-extension/roi2-M2-M3-local-registration-candidate-v23.json)。S1候选投影约(2323.48,3190.07)，S2约(2323.01,3209.21)。两点均在L01右端短竖段附近，因此当前候选提示“两孔可能接同一根物理M3”，不是直接各选一条横线；导体身份仍待核，已审的两孔身份不撤回。该假设不能靠未通过验收的变换升级为确认。

[十条M3编号对照](../runs/roi2-M2-M3-registration-v23/M3-all-local-numbered-review.png)、[L01宽原图对照](../runs/roi2-M2-M3-registration-v23/S1-S2-L01-candidate-wide.png)、[M3原生编号图](../runs/roi2-M2-M3-registration-v23/M3-numbered-native.png)、[原生路径](../benchmarks/metal-extension/roi2-M3-local-numbered-inventory-v23.json)。L01橙色为S1/S2目的导体候选，其他青色线仅作编号参考，不表示接入gate，也不宣告隔离。L01横段约(1228,3242)至(2320,3210)，右端向上短段约至(2324,3185)，所有几何均为AI中心线候选。L09沿用已审A-C物理线并保留鼠标遮挡显示缺口，不作为电气断开。

T尚未可靠配准。仿射外推T≈(2332,2208)，四点射影外推≈(2339,2273)，分歧约65px，因此拒绝用下方模型选T处M3。用户“追踪两条M3”不转换为“两孔必须各接不同M3”的约束；当前两孔可能共用L01，T是另一待配准接口。尚未点亮/确认全部目标网。

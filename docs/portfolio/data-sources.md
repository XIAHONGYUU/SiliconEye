# 样本来源与使用范围

本项目使用同一颗芯片的8张逐层观察照片。根据项目所有者在本次开发对话中的说明，显微镜采集为光学观察，现有输入是其手工拍摄显微显示屏得到的照片；原始显微图像无法取得。它们不是本项目拍摄的SEM数据，也不是从公开数据集下载的样本。

原始文件保存在data/test_chip/tile_full/，不在源图上绘制或重编码；展示页使用副本裁片与结构数据，来源哈希见[provenance.json](../../site/provenance.json)。规则重建用于探索AI与专家协作的材料理解、几何表达和连接复核流程。

采集方式、公开权限和许可是不同信息。目前未在仓库附上第三方芯片/图像的独立授权材料，因此本页只说明已知来源，不替第三方作授权声明。软件包中的代码许可不自动构成芯片照片或第三方设计的许可；也不把样本称为可自由再分发的开放训练数据集。后续引入公开样本时应逐组记录作者、来源页、许可与允许用途。

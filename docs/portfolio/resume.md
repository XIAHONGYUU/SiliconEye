# 简历项目表述参考

以下文字以本项目当前已实现的范围为准，不包含全芯片自动提取、真实工艺DRC/LVS或仿真就绪网表等研究目标。可按目标岗位裁剪，不需要全部写进简历。

**Silicon Eye｜模拟芯片图像重建与AI协作工作流｜个人项目**

- 主导基于同颗芯片8张逐层照片的重建流程，将模拟版图中的材料、共享扩散、栅端和过孔承载知识转化为结构约束与复核规则。
- 采用AI辅助开发Python/OpenCV/Shapely工具，形成AA/POLY/CT共同工作层、器件跨层编号、局部连接表达及五层导体联合复核页面。
- 设计AI判断、脚本执行和人工裁决的职责边界，实现稳定ID、来源哈希、局部增量修订与防退化质量门，并沉淀材料/导体重建skill。

**作品入口：** [交互Demo](https://xiahongyuu.github.io/silicon-eye/) · [GitHub](https://github.com/XIAHONGYUU/silicon-eye)

面试中可重点展开三个实际问题：为什么不能只按照片颜色分割；为什么完整孔组能排除错误承载；怎样在修订一处几何时保留其他已审结果。区分本人负责的领域判断/架构/验收与AI辅助生成、实现和调试的部分。

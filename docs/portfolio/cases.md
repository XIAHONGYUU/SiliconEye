# 精选案例与证据

本页对应[交互Demo](https://xiahongyuu.github.io/SiliconEye/)的三个案例。展示只是精选入口，源数据、原生坐标及批准范围均保留；不是另一次自动识别结果。

## 01 材料规则重建

问题：手工拍摄的光学显微照片存在倾斜、明暗变化和混层。直接二值化轮廓容易把相邻AA粘连、漏掉POLY栅端或混淆CT所属材料。

方法：算法提供候选，AI结合上下层和模拟版图结构复核；使用规则几何表达工作层，关键身份由人工裁决，局部修订不重做已审区域。

展示：切换AA/POLY/CT局部工作几何和来源邻域。两者分别保留坐标，不声称精确照片投影。共同输入为[joint-work-layer-v5](../../configs/joint-work-layer-v5.json)，身份修订依据见[来源归属裁决](../reviews/2026-10-21-source-ownership-adjudication.md)。

## 02 器件编号与局部连接

问题：照片检查框、MOS栅指、端子和电路表达需要稳定对应，未知连接不应被显示成断开或被默认补齐。

展示：两条已审MOS栅指R2_Q1/R2_Q2，选择编号联动原生POLY范围、宏观投影M1查找范围和端子表；附已有局部电路表达。AA缺少逐器件定位时不画框，A/B端不强行指定源漏方向。

输入为[器件复核包请求](../../benchmarks/review-package-roi2-device-index-v1.json)，该请求引用冻结case和人工裁决。[编号视图说明](../device-index-v1.md)保留来源、验证及范围限制。公开演示只展示已实现的编号和关系查询，不把检查框当作已测量器件边界。

## 03 五层联合复核

问题：看见上下金属交叠不能直接判断连接；完整孔组的宽度可能排除错误的窄金属承载，跨层V1/V2却可以投影重叠。

展示：P08→V1→J01→V2→B1的局部连续路径，五层开关、孔组放大、已审接口与候选几何分开。V2的3×4数量来自既有人审；V1为AI观察的规则候选。最新重叠偏移仍待复核。

输入为[堆叠孔修订](../../benchmarks/stacked-via-review-v2/review-request-v1.json)，[修订报告](../reviews/2026-10-25-stacked-via-correction.md)保存定性反馈、局部变更及149项相关回归。测试数是该组工程验证，不是准确率或全项目测试总数。

## 展示的可追溯性

[site/provenance.json](../../site/provenance.json)记录照片、模型、器件包及展示资产的SHA-256。器件包由既有命令重放生成，构建参数集中在[portfolio.json](../../configs/portfolio.json)。浏览器只查看冻结数据，不会实时调用AI或生成新的物理结论。

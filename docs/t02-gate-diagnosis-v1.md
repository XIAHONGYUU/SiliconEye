# T02 为什么未过门：观测中心定义敏感，尚不能认定几何提取错误

2026-10-18。用户认为 T02 没有明显提取错误，本轮按只读诊断检查原因；没有修改重建几何、照片变换、质量门参数、原人审状态或生产代码。原运行 v1f 的失败数值保留。

## 失败项是什么

T02 的七项结构/几何落点规则均通过：有效性、水平/竖直、槽位数量与唯一性、共享尺寸、基线/节距/形状、成员分离和 AA 几何落点。唯一失败项是照片回投观测一致性：中位偏差 5.19697 px > 4 px；P95=5.60063 px < 8 px。沟道禁区、上覆金属、工艺规则仍待定，模板外亮点仍未解释。

因此原报告“真实失败”应理解为这项观测一致性实验未过门，不能据此表述为 T02 的材料结构或孔数已被证明提取错误。用户“没有明显错误”是宏观反馈，不在本轮自动写成精确位置/孔数/电气连接的正式批准。

## 偏差集中在哪里

27 个模板孔中，上下两排的 18 个观测用于拟合，中排的 9 个观测用于验证。9 个验证点不是分散在不同排：它们相对投影位置全部偏上，投影减观测的平均垂直差为 +4.55 px、标准差约 0.81 px；水平平均差只有 +0.22 px。

各列旧亮点参考的上→中距离约 9.5–11 px，中→下约 15–21.5 px。模板采用等间距，所以投影中排接近上下排中点，和偏上的旧中排参考产生稳定差距。例：一列参考纵坐标为 1240、1250、1271 px，中点是 1255.5 px，中排亮点参考相对中点偏上 5.5 px。这里的数字是局部亮点位置，不是独立测量的真实孔中心。

## 参考点定义的影响

旧参考来自 `scene_geometry.extract_peaks`：在平滑图中找局部极大值，再取极大值连通块的中心。它估计的是局部亮度峰位置，没有独立恢复整枚 CT 的几何中心。拍屏条纹、亮度不均及孔内多个高亮像素均可能影响峰的位置；本轮没有独立证据量化各成像因素的具体贡献。

为检查敏感性，在旧参考附近 9×9、11×11、13×13、15×15 小窗内，用扣除局部低亮背景后的亮度加权中心作替代参考。只作诊断，不作为新真值，也不按过门结果挑参数写入生产算法。

| 中心定义 | 原变换保持不动的中位差 | 同模型重新拟合后的中位差 / P95 |
| --- | ---: | --- |
| 原局部亮度峰 | 5.20 px | 5.20 / 5.60 px |
| 9×9 加权中心 | 4.73 px | 4.30 / 4.80 px |
| 11×11 加权中心 | 4.33 px | 3.57 / 4.31 px |
| 13×13 加权中心 | 3.94 px | 3.01 / 3.78 px |
| 15×15 加权中心 | 3.88 px | 2.93 / 3.67 px |

13×13 方法相对旧参考的全体位置移动中位约 1.86 px。几何、原投影和门限完全不变时，仅替代参考定义就能使中位差跨过 4 px 门限。这是判定对观测定义敏感的证据，不是替代中心已正确或 T02 已通过的证明。小窗可能混入邻近纹理，需单独验证其定位可靠性。

用原参考将变换改成仿射，留出中位差仍为 5.10 px，与单应的 5.20 px 接近。单纯在这两类变换间切换没有解除冲突；不能据此排除所有局部畸变或模板误差，但不支持直接靠增加拉伸来解决。

## 对质量门的判断

数值计算和阈值比较本身没有发现实现错误。问题是参考位置没有达到独立几何真值的地位，4 px 又是未经成像定位不确定性标定的工作门限；将这一项失败扩大解释为“结构提取错误”，证据不足。

建议的后续修订是：几何/阵列/合法区结构规则作为对应用途的门；照片一致性检查显式记录中心定义与定位不确定性，对无法可靠定位的孔返回待定；按单元或交错位置选择验证样本，避免某排系统偏差冒充全部结构错误。沟道和上覆材料缺失仍待定。质量门的参考定义及适用范围先验证，不能只放宽阈值或把人工宏观认可当精确像素真值。

本轮结论：保留 T02 的规则几何候选，优先修订观测参考及判定口径。原数值失败状态不追溯覆盖，不以本次敏感性实验宣布正式通过。
